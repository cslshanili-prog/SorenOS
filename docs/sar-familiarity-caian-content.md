- ★4、★5 沒有補寫內容。

## 選項和流程整理

文檔大量使用選項簡稱作為分支名，實現保留用戶看見的完整選項，直接連到對應台詞。需要特別說明的錯名是：

| 原選項 | 原分支名 | 實現 |
| --- | --- | --- |
| C2-02 玩過 | 提過 | 對應“你也玩過啊！” |
| C2-08 喵 | 不許貓語 | 對應“我還沒說！” |
| C2-10 那我走了 | 路過 | 對應“等等啊！” |
| ★2 Zzzzzzz…… | ZZZzzzz | 對應“抱歉，很無聊對吧？” |

C2-02 最末句“如果是你的話，我還挺想知道你玩完會怎麼想。”作為三個選項共同收尾。

★1“什麼記錄？”只有說明而沒有明確同意落點，因此在說明後補用已有“好啊 / 不要”選項。拒絕直接進入道別，不生成成員卡。未改寫角色台詞。

保留原文“想跟別你講話”等字詞，沒有擅自潤色。★2 拒絕後仍回到正式問題是原劇本走向；閱讀器可隨時離開並保存斷點，提供場景之外的退出能力。

## 演出和紀念物

| 事件 | 數據節點 / effect | 當前實現的行為 |
| --- | --- | --- |
| ★1 管理員證 | photo / admin-card | 凱恩 chibi 作為正式管理員證證件照 |
| ★1 成員登記 | member-card / membership-card，interactive | 用戶明確同意後，確認或調整自己的 chibi，生成 SAR 成員 #0001 卡；成員名使用用戶當前名稱 |
| ★2 會議記錄 | meeting-record | 顯示會議議題、三位參與者、選擇對應的結論和“討論仍然有意義”備註 |
| ★2 合照 | photo-studio，interactive | 三位 chibi 可移動與縮放、用戶可修改自己的 chibi、可加入自己的角色、選擇活動室背景；確認拍照後發紀念照片 |
| ★2 照片展示 | photo-reward / notice | 顯示日期及照片背面的凱恩字句；照片包含用戶角色時，補顯示“似乎朋友們也都在！” |
| ★3 舊式卡展示 | spare-card / memory-card | CSS 繪製空白存檔卡的展示，此處尚未發放 |
| ★3 獲得卡片 | reward / memory-card | 空白存檔卡入紀念物，保留略歪的“（User名） / 彼方”標籤與完整說明 |

紀念物 ID：`caian-membership`、`caian-meeting`、`caian-photo`、`caian-memory-card`。由共享引擎在首次離開相應獎勵節點時原子發放；回放不得重複發物品。

對話默認只有凱恩居中；艾文實際發言時臨時雙人同框，凱恩再次講話即回到單人。提及艾文或設置聽者情緒不會觸發出場；敘述沿用最近說話者，續讀與回放相同。凱恩七種表情已在 `public/sar-portraits/Caian` 本地提供，艾文插話使用其六種本地表情；特殊演出保留台詞旁的情緒頭像。

會議結論存在選項的 `flags.meetingConclusion`，分別為“未得出結論”“肘擊系統？（被駁回）”“下次再議”。會議記錄文本的 `{{meetingConclusion}}` 由閱讀器/獎勵存檔替換。

照片編輯的日期、位置、縮放、背景、用戶形象與加入的角色由交互演出保存；內容文件不偽造照片編輯結果。

自己的倉庫「紀念」可查看上述證件、會議記錄、合照與存檔卡，保留獲得當時的姓名和圖片，不隨之後換形象重拍。「圖鑑 → 名冊 → 回憶」重看已完成劇情，未完成標題不劇透。完整 ZIP 備份帶走照片及其嵌套本地圖片引用；純文字備份保留劇情進度、紀念文字和構圖，剝離圖片。

## 日常對話

通常組合為“時段 + 天氣 + 星期”三句。星期數組按 `Date.getDay()`，0 為週日。當前個人線入口使用世界 seed 與日期確定的彼方模擬天氣：clear 對應晴天，rain / storm / snow 歸入雨雪類，其餘歸入陰雲類；底層也支持傳入明確的天氣類別。這不是額外請求真實天氣或模型生成的一段說明。
