# SAR 敘事與世界意志

當前實現核對：2026-09-11。

異格檔案輸入框的回車僅換行，點擊發送按鈕才發起推演。用戶消息的操作菜單支持修改錯字與多行文本；保存沿用原 ID、時間和幕序號，不消耗互動次數，不重寫後續劇情。修改後清除這一幕及之後回覆的派生導演狀態，後續生成和全文導出讀取修正後的原文。事務內校驗消息所屬故事和舊值，避免跨故事或過期編輯覆蓋。

用戶提出的核心原則：**世界負責產生故事，用戶負責決定如何生活在故事之中。** 世界可以比用戶知道的複雜得多，複雜性由世界承擔，理解成本由敘事負責消化，選擇權留給用戶。

## 產品要求

1. 用戶是參與者，不承擔編劇、推進主線或維持節奏的責任。參與、拒絕、忽略、離開與改變關注點都成立。
2. 無需理解也能參與。先呈現受影響的人、可感知事件、生活後果與當前意義，再解釋複雜原因。
3. 漸進展開世界觀。現象與後果 → 簡單原因 → 設定細節 → 深層機制；僅隨用戶持續探索加深，停止追問就停止加深。
4. 鏡頭跟隨當下關注。關係、親密、日常、喜劇、探索、冒險與主線可以隨對話切換，不設置用戶必須選擇的模式。
5. 沒接住劇情時減輕信息負擔。短回覆只是弱信號；困惑先用普通話解釋，明確拒絕優先於推測出的興趣。
6. 角色擁有自己的判斷、計劃、私心與行動，不充當世界觀考官，不把下一步的思考責任交給用戶。
7. 事件首先是鉤子。可以被別人處理、自然結束或以後產生新後果；拒絕後允許退場，不換說法重複催促。
8. 世界意志承擔隱藏導演職能。用戶看到可感知的故事，不看到調度分析、興趣評分、秘密或未來劇情規劃。
9. 主線不霸佔生活。吃飯、陪伴和安靜相處同樣構成經歷，世界意志可以選擇什麼都不打斷。
10. 自由來自世界中真實存在的可能性。角色可以拒絕、離開、隱瞞與犯錯；用戶仍決定自己的行動、感受、台詞和立場。
11. 目標是讓用戶想“這裡正在發生事情，而我現在想做什麼”，而不是“我該說什麼才能讓劇情繼續”。

## 共同確認的邊界

- 不把所有被忽略的事件改成親近的人受傷、失蹤來強拉主線；後果來自已建立的因果，不能懲罰用戶沒有接鉤子。
- 保留所選模塊的氣氛與真實危險，不把所有題材改成日常。既有危險可以由角色應對，也可以產生合理後果。
- 故事時間不等於互動輪數，十句對話可能只過去兩分鐘。場外行動遵守時間、距離、能力和既有事實。
- 五十輪保留為產品篇幅與收束邊界。收束實際參與的關係和經歷，允許世界中的主線未解決。末輪可用既定返航機制關閉連接，不代寫用戶主動走進出口或接受某種結局。
- 旁白允許為空；內部記錄只保存少量事實，不保存推理過程或用戶人格評分。敘事自主在每次用戶互動內完成，不增加後台自動調用。

## 實現

這套世界意志規則用於芯片鑄造與五十輪生成式演繹。凱恩、艾文的 [個人線](./sar-personal-lines.md) 則按用戶原稿運行固定分支，不交給世界意志補寫、不新增模型調用，也不沿用五十輪計數。個人線每日機會按本地自然日記錄；推演中的故事時間仍遵守當前場景，不能把二者混為一套時鐘。

個人線只在用戶點 NPC 後進入，支持離開、斷點續讀和已完成回憶重看，不打斷其他玩法。五顆星只實現有原稿的一至三星，四、五星保持未開放。鏡頭默認本人單人居中，對方實際發言後保持當前小段雙人同框；跨節點查看後續六句是否還有對方台詞，避免輪流說話時反覆退場。敘述延續最近說話者。台詞逐句點擊推進，選項居中浮現，不擠佔立繪。初遇被拆台的尷尬表情在凱恩接話時揭示。特殊演出仍保留當前人物情緒，贈品只按程序確認的獎勵入庫，回放不重發。

`utils/vrWorld/sarNarrative.ts` 提供統一運行規則，以及有界的 `sceneFacts / openThreads / offscreenFacts / declinedHooks / revealedFacts` 快照。每項最多六條，每條最多 180 字。缺失或不完整快照不覆蓋最後一份有效記錄。

鑄造、運行和五十輪階段統一遵循上述規則；舊卡的強制任務描述只作為初始背景參考，已發生事實保留。世界與角色在同一次模型請求中生成，連續性快照保存在該回復的消息元數據裡。空旁白正常解析；損壞的結構化輸出報錯，避免將內部字段顯示為正文。

身份卡默認展示簡介與開場；背景摺疊，不展示隱藏真相和預設抉擇。演繹以正文為主，資料、主題、進度與封存進入次級頁面。封存正文導出只含用戶可見內容。

## 驗證範圍

單元與瀏覽器檢查覆蓋空旁白、私有記錄、舊文本回退、損壞 JSON、刷新續寫、失敗不計輪、封存與五十輪結尾、主題、小屏和重讀位置。瀏覽器使用獨立存檔和模擬模型回覆；它驗證程序契約，不代表所有真實模型的敘事質量已被評測。
