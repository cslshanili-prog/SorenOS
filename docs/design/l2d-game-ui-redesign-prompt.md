# SullyOS L2D 桌面與視頻通話改造提示詞

## 任務角色

你是 SullyOS 的遊戲 UI / UX 設計師與前端工程師。請直接在現有產品中優化 L2D 桌面和視頻通話界面；保留原有角色、背景、通話能力和數據結構，不生成帶界面的背景圖，不用大量互相競爭的卡片掩蓋角色。

## 參考圖提煉

- 角色必須是第一視覺中心，像二次元養成遊戲主界面的“看板娘”，而不是被面板夾住的普通預覽圖。
- 功能圍繞角色分層：頂部只放身份與輕狀態；左右放低頻快捷入口；底部放最常用主操作；所有控件主動避讓臉部和身體重點區域。
- 從參考圖吸收輕巧的遊戲語彙：圓形或異形快捷按鈕、絲帶式導航、微型通知點、任務/親密度狀態、閃光與漂浮裝飾、按下回彈；不要照搬資源貨幣、商城和十幾個入口。
- 視覺兼顧 SullyOS 現有的夢幻感與現代清晰度：奶油白 / 深夜藍作為穩定底色，角色主題色作唯一主強調色，小面積使用櫻粉、星光金或薄荷色。
- 視頻通話更像“角色正在陪伴你”的沉浸舞台：信息與字幕貼邊，控制器懸浮在下方，背景設置與高級工具退到抽屜中，避免遮擋角色。
- 桌面支持多個一鍵切換的佈局預設，讓趣味性來自不同構圖，而不是來自更多控件。

## 視覺論點

把整個屏幕做成一張會呼吸的角色海報：柔軟半透明材質、遊戲式輪廓按鈕與清楚的舞台景深，讓 L2D 像住在桌面裡。

## 內容計劃

1. 角色舞台：全屏背景 + L2D 主體，保持最大可視面積。
2. 頂部狀態：角色身份、在線/情緒狀態、時間或通話時長，保持單行易掃。
3. 快捷操作：桌面按佈局預設分佈在側邊或底部；通話只保留麥克風、輸入、設置、掛斷等核心操作。
4. 情境信息：桌面顯示一句輕量角色狀態/氣泡；通話顯示對話字幕和當前收音狀態。
5. 構圖編輯：單獨進入編輯模式，提供拖拽移動、縮放、橫縱位置、可視窗口/裁剪以及重置和保存；編輯時顯示安全框，退出後完全隱藏。

## 佈局預設

- `舞台 Stage`：角色居中偏下，左右各一列小型圓形入口，底部弧形/膠囊主導航；最接近日系養成遊戲主界面。
- `陪伴 Focus`：角色更大並偏一側，另一側只保留角色狀態與三枚常用入口；適合欣賞角色和寬屏。
- `輕巧 Mini`：角色偏下，功能集中為底部短托盤，頂部信息極少；適合小屏和不遮擋模型。

佈局切換必須即時、有平滑位移動畫，並記住用戶選擇。每套佈局共享同一份角色構圖數據，避免切換後人物跳回默認位置。

## 角色構圖編輯要求

- 桌面 L2D 必須支持直接拖拽角色定位。
- 提供縮放滑桿和 `放大 / 縮小 / 居中 / 適配 / 重置` 快捷操作。
- 支持 X / Y 偏移與裁剪窗口（至少上、下、左、右四個邊界或等價的可視框編輯）。
- 實時預覽，保存到角色自己的配置；取消時恢復進入編輯前的數據。
- 限制極端數值，避免把角色完全拖出屏幕；提供可見安全框和當前百分比讀數。
- 手機觸摸與鼠標均可操作；控件可收起，不長期遮擋角色。

## 交互論點

- 進入桌面時：背景輕微推近、角色柔和上浮、功能按鈕分批出現，完整過程快速且克制。
- 切換佈局時：按鈕沿邊緣滑到新錨點，角色舞台不閃爍、不重新加載。
- 角色交互時：點擊/觸碰出現短促星屑、愛心或波紋反饋；主按鈕按下有彈性回彈；通知點輕微呼吸。

## 驗收標準

- 第一眼先看到角色，再看到最重要操作；不能出現面板比角色更搶眼的情況。
- 常用功能 1 次點擊可達，佈局切換與構圖編輯不超過 2 次點擊。
- 小屏 360×640、常見手機 390×844 和桌面窄窗均不溢出；劉海屏安全區有效。
- 不破壞現有 VRM / Live2D 加載、通話、語音輸入、背景選擇和動作配置能力。
- 動畫尊重 `prefers-reduced-motion`，按鈕有可讀標籤和足夠觸控面積。
