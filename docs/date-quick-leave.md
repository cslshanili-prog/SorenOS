# 見面 · 快速離開與「見面中」

見面聊到一半想去看一下別的訊息，以前要五步才回到桌面（選單 → 離開 → 保存並退出 → 選角色頁 → 返回），要進某人的私聊還得再點三下。現在：

| 想做什麼 | 怎麼點 | 步數 |
|---|---|---|
| 回桌面 | 見面右上「⋯」→「回桌面」 | 2 |
| 去某人的私聊 | 「⋯」→「去私聊」→ 點那個人 | 3 |
| 看所有訊息 | 「⋯」→「去私聊」→「所有訊息」 | 3 |
| 回到見面 | 點頂端「見面中 · TA」，或從任何入口打開見面 | 1 |

原本的「離開」（保存並退出、回選角色頁）照舊，給真的要結束這次見面的時候用。

## 掛起

見面在**會話階段**被卸載、又不是點「保存並退出」或完結故事退出的，就算掛起：選單的兩顆新按鈕、來電、點通知跳走都一樣。感知階段（還沒開口）走開不掛起。

- 掛起狀態在 `utils/dateSuspend.ts` 的 `dateSuspend`，**只在記憶體裡**，重新整理頁面就沒了，跟「通話中」一樣。會話進度本來就由 `DateSession` 寫進角色的 `savedDateState`（卸載、切背景、每 30 秒都存），所以重新整理後進見面照樣能「繼續上次」，不會丟東西。
- 打開見面時（`apps/DateApp.tsx`）有掛著的就直接接回去，不經過選角色頁、也不彈「發現進度」。接回去走的是「繼續上次」同一套（讀故事、武裝崩潰哨兵、切回那個角色）。
  - 有別的直達意圖（劇場、更新彈窗帶的 `dateLaunch`）就不接，那條「見面中」留著。
  - 從私聊「見面」進來的：是掛著的那個角色、又不是拿邀請卡赴約，就接回去；換了別人就把掛著的那場放掉，走原本的流程（進度照樣在存檔裡）。
  - 原本是從私聊進的見面，接回來之後點「保存並退出」照樣回私聊（`cameFromChat` 跟著掛起狀態一起記）。
- 「保存並退出」、完結故事、在「發現進度」選繼續或重新開始，都會清掉掛起。

## 沒送出的字、還在生成的那一輪

- 輸入框裡打到一半的字按角色記在 `dateDrafts`（記憶體），回來時輸入框直接打開、字還在；送出就清掉。
- 送出／繼續／重新生成都包在 `dateInflight.track` 裡。走開時那一輪還在跑，請求照常跑完並落庫（這本來就會發生）；接回來時畫面看到它還沒落定，就顯示「正在輸入」、不讓再送一次（`DateSession` 的 `externalTyping`），落定後重讀一次記錄，新回覆直接出現。

## 「去私聊」小表

`components/date/DateQuickChatSheet.tsx`，排序在 `pickQuickChatTargets`（有單測）：

- 有未讀的排最前面，其餘照最後一則私聊的時間排，沒聊過也沒未讀的不列；
- **最多 5 個人**，最後一行固定是「所有訊息 →」（打開訊息列表）；
- 只列私聊，群聊走「所有訊息」；
- 見面的這個角色自己也會出現在表裡（去私聊 TA 也是常見的事）。

點進某人的私聊時 `chatReturnTarget` 設成訊息列表，在私聊按返回會回訊息列表。

## 頂端那條（也修了「通話中」點不到）

`components/os/SuspendedSessionBars.tsx`，「通話中 · TA」和「見面中 · TA」都在這裡，兩個同時有就上下疊。

位置一律從安全區下緣起算（`top: calc(var(--safe-top) + 4px)`）。以前「通話中」寫死 `top: 28px`：有劉海或動態島的 iPhone 頂端前 47～59px 都是系統狀態列，點擊會先被 iOS 拿去做「點狀態列捲回頂端」，那條整個落在裡面，所以怎麼點都沒反應。

代價：這條會稍微壓到 App 頂欄中間（標題那一帶）。鎖屏時不顯示；在電話／見面 App 裡面時不顯示自己那條。

## 統計

`见面快速离开`（去向：桌面／私聊／所有消息）、`回到挂起的见面`，見 [`analytics.md`](./analytics.md)。

## 上游的同類功能

上游 SullyOS `03889c9`（2026-11-11）做了「見面掛起與離開提醒」。掛起那半上游是記在記憶體裡、回來原樣恢復，因為他們拿掉了「繼續上次」；Soren 留著「繼續上次」，所以只補「不用再選一次就回去」和頂端那條，存檔照舊。離開提醒（走開太久角色到私聊找你）沒搬：它建在上游的「離開後消息」上，那是上游拿掉主動消息 1.0 之後的替代品，Soren 的 1.0 還在。
