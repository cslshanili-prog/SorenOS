# 劇情預設自定義分組

在預設製作器的「專業版」首頁輸入分組名稱，點「新增分組」。新分組可以為空；點進去後用「在本區新增提示詞」添加內容。打開已有提示詞後，可以用「移動到分組」調整所屬分組。

自定義分組支持改名、整組上下移動和取消分組。取消分組保留全部提示詞，重新放回未分組區域。內置預設需先點「複製調整」；「角色與世界」等系統連接位保留原有保護規則。

分組邊界保存在原生預設的 `prompts[].section` 中（id / name / edge），隨保存、複製、備份和 JSON 導入導出保留。邊界不發送給模型，提示詞仍按數組順序發送；不帶分組信息的舊預設照常顯示為「自定義條目」。

劇情重寫排除本劇情在角色時間線中的鏡像，避免舊版本通過角色近期原文迴流。生成成功後在一次事務中原位更新中央正文和鏡像；請求失敗、併發修改或刪除時保留原狀態。重寫不會額外發起第二次模型請求。
