# 家園觀測順序與進度

`world_episodes.createdAt` 是觀測完成時間；`round` 是劇情/手機消息引用使用的輪次。舊世界狀態被界面快照覆蓋時，可能出現兩個相同 round、realClock 回退，導致下一輪再次演繹上一時段。

- `DB.getWorldEpisodes` 先按完成時間排列全部記錄，再截取最近若干條。主界面、角色房屋和手機都使用返回的第一條作為最新觀測。
- 讀取時計算 `observationNumber` 作為紀事顯示序號，兼容已存在的重複輪次。該字段不落庫，不改寫歷史 round、消息關聯或劇情內容。
- 引擎在佔用運行鎖後重新讀取世界及最近歷史，通過 `recoverWorldProgress` 恢復被覆蓋的計數。現實模式計數落後時，使用歷史的明確日期/時段標籤恢復 realClock；正常計數下不干預用戶換時區後的時鐘調整。
- 現實模式的凌晨屬於前一劇情日的 seg=3，但標籤顯示次日日期。不要把觀測完成時間強行當作劇情時間：補演、慢請求等都可能讓二者不同。
- 界面編輯用 `DB.updateWorld` 在事務中對最新世界打補丁；世界設置只保存相對打開編輯器時發生變化的字段，避免舊草稿覆蓋後台推進的 storyClock/realClock。

已有錯誤劇情標籤無法僅憑完成時間可靠判斷原本應該演哪一段，因此保留；恢復的是顯示順序、顯示編號和後續觀測進度，不重新調用 API 或重寫歷史劇情。
