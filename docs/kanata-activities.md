# 彼方：活動選擇與自動活動範圍

## 用戶入口

「彼方 → 接入 → 角色 → 讓 ta 現在去逛一次」先選擇兩個大分類，再選擇玩法：

| 分類 | 子玩法 |
| --- | --- |
| 普通空間 | 圖書館、劇院、聽歌房、留言簿、娛樂室、郵局 |
| SAR 活動室 | 抽芯片演繹、模塊商店、水域釣魚、佈告板、恐龍箱庭 |

首層提供「隨便逛逛」，SAR 二級菜單提供「在活動室隨便玩一樣」。返回箭頭、系統返回與 Esc 先回到大分類，再關閉選擇器。菜單沿用系統安全區，矮屏採用兩列布局。

抽芯片演繹對應角色既有的臨時芯片與隨筆玩法，包括抽取與推演；不是替用戶操作付費扭蛋或發用戶藏品。倉庫、圖鑑、凱恩和艾文個人線屬於用戶操作，不加入角色活動池。信號墜落處仍走專門的活動入口，不進隨機池；尚未開放的研發中心也不列入。

圖書館受角色閱讀範圍約束；範圍內無書時禁用並提示。恐龍箱庭需要開啟共同擺弄且桌上有恐龍，未滿足時顯示具體原因。手動邀請箱庭沿用既有手動來訪規則，不自動開啟共同擺弄。

## 高級選項

每位角色卡片下方的「高級選項」默認摺疊，可勾選 **不自動去** 的普通房間，以及 **不自動玩** 的 SAR 子玩法，也可以排除整個 SAR 活動室。

- 只影響該角色的自動自由活動；手動邀請（包括手動隨機）仍可前往，玩法本身的可用條件繼續檢查。
- 關閉整個 SAR 時子項顯示為全部排除，但原單項選擇保留；重新允許 SAR 後恢復原單項選擇。
- 全部排除時跳過自動活動，不調用模型，不算 API 失敗，不自動擴大活動範圍。
- 排除全部可用 SAR 子項時，SAR 本身也退出房間隨機池。只允許箱庭、但箱庭條件/自動來訪額度不滿足時同理。
- 正在執行的一輪可以完成，更新只影響後續輪次。活動結果保存時以最新排除設置為準，不把舊開關寫回來。
- 「恢復全部可去」清空排除項。限制不改變接入開關或活動間隔。

## 實際選取流程

佈告板活動允許角色選擇 `sell`，把自己倉庫中一條或多條可用魚獲一次交給艾文（關閉 NPC 時交給回收站）。`CATCHES` 為魚獲 ID 的 JSON 數組；每條按結算時的當日行情與品質計價，整批一次入帳、一次移除庫存、生成一張回執，艾文只回復一次。沿用每日回收額度和錢包上限，不能出售別人的魚、掛單中或尚未完成釣魚結算的魚、橡皮泥模型；任一項失效或整批超額時整筆不成交，圖鑑歷史保留。用戶首次進入市場板會播放 2026-09-16 的凱恩通知，完整看完才記錄已讀；上一版通知的已讀狀態不影響本次。

自動活動由程序隨機選擇，不是把所有設施操作交給模型選：

1. 按實際內容和角色設置生成可用房間池，移除禁用房間。
2. 從剩餘房間隨機選一個。圖書館要有可讀書，聽歌房要有歌單或正在播放的歌。
3. 若選中 SAR，再從滿足條件且未禁用的 SAR 子玩法中按權重選一個。
4. 只准備本房間/子玩法的現場信息與操作提示，帶入角色原有人格和上下文，調用一輪模型。
5. 程序校驗並執行本輪輸出，保存動態和相關狀態。模型可以決定本玩法裡的具體表達或動作，不通過本輪執行器跨房間操作。

本次兩大分類只是 UI 整理，不將普通空間與 SAR 的概率改成各 50%。未設置排除時保持舊隨機權重；過濾後在剩餘候選中重新歸一化。SAR 原權重：釣魚 30、佈告板 20、模塊 21、芯片演繹 29；箱庭滿足自動來訪條件時佔 20，模塊相應變為 1。箱庭的冷卻與每日來訪限制繼續沿用原實現。

## 實現與兼容

- `utils/vrWorld/activityChoices.ts`：可執行子玩法目錄、SAR 權重和過濾規則，UI 與執行器共用 ID。
- `VRWorldCharState.excludedAutoRooms` / `excludedAutoSARActivities`：每個角色的排除項，缺省或空數組表示不限制；隨角色備份保存。`VRSARActivity` 集中定義五種子玩法。
- `VRActivityPicker.tsx`：兩級手動菜單與高級選項。高級選項使用函數式角色更新，避免快速連續勾選覆蓋上一項。
- 手動鏈路為 `triggerNow(charId, room, letterId, sarActivity)` → 回調 `(charId, room, letterId, manual, sarActivity)` → `runVRSession.forcedSARActivity`。原郵局指定信件的參數位置保持不變。
- `runSession.ts`：自動活動在房間層和 SAR 層都過濾；指定的房間/活動不可用時跳過，不隨機替換成另一項。
- `participation.ts`：活動結果落庫保留最新排除設置。
- 模塊商店獨立使用逛店說明，不混入芯片演繹操作；沒有改動角色經濟額度、模塊購買結算或主動消息系統。

驗證：`activityChoices.test.ts`、`fishingSession.test.ts` 覆蓋過濾、全禁用零模型調用、手動繞過、完整路由、舊概率、舊參數兼容及最新配置保護。`scripts/test-vr-activities.mjs` 在隔離瀏覽器驗證菜單、持久化、備份和安全區。

佈告板手動刷新中的多人路人生成見 [佈告板路人群像](./sar-market-npcs.md)。這條路徑一輪生成多位路人的公開互動，自家角色仍沿用本頁的獨立活動流程。
