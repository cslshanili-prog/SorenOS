# 一週年贈禮

九月是開始做小手機項目的一週年，不指定某一天。贈禮是一位老玩家提供的兩張壁紙和一個頭像框，作者均為 **哈基米欠我錢**。原文件保存在 `public/anniversary/`，沒有裁切、重繪或壓縮。

作品只通過週年彈窗贈送，不作為長期內置素材。外觀、聊天背景和氣泡工坊沒有周年素材的常駐自選或一鍵安裝入口。保留原圖的穩定路徑，讓已應用的壁紙和頭像框繼續正常顯示；用戶自己的已保存主題仍可正常編輯。

- **彈窗**：設備當地的 2026 年九月，數據和開機動畫就緒、解鎖並處理完免責聲明及導入恢復提示後，優先顯示 Ta-da 週年贈禮；關閉或成功應用後再顯示更新公告及後續提醒，同時將 `sullyos_first_anniversary_seen_v1` 記為已讀。本會話還有一次性保護；不依賴角色時區，不會在下一年重複週年活動。
- **免費贈禮**：累充展示固定為 `¥ 0.00`，僅是贈禮的玩笑文案，不涉及餘額、支付或 API。兩頁彈窗都顯示作者署名。
- **下載全部**：左側按鈕一次導出一個 ZIP，包含兩張原始 JPG、一張透明 PNG，以及帶作者署名和頭像框位置參考的說明。複用其他活動的 `shareOrDownloadBlob`：原生客戶端拉起系統保存/分享面板，網頁端也優先嘗試文件分享，無法分享時才退回瀏覽器下載；不設置跳過 Web Share 的選項。取消分享後不會額外下載，也不會提示保存成功。任意圖片下載失敗或返回錯誤頁面時，不生成缺圖的壓縮包；可以重試。導出不會改變裝扮或自動關閉彈窗，之後仍可換裝。
- **一鍵應用**：右側「立即換裝」進入選擇頁，用戶選一個角色，再勾選頭像框、聊天背景、手機桌面壁紙，最後「確認換裝」。兩個背景各自可選款式；頭像框給這段聊天中的用戶和角色一起戴。確認後，整機同步切回原默認紫色風格（複用 `NOSTALGIA_APPEARANCE` 的配色與佈局，淺色畫作使用深紫桌面文字），自動動森葉子隨皮膚移除。壁紙只替換勾選項，獨立鎖屏壁紙仍遵循已有規則。僅下載或關閉不會切換主題。
- **底部操作**：並排切角按鈕，左側淺色「下載全部」，右側紫金色「立即換裝」。短暫掃光、懸停和按壓反饋遵循系統減少動態效果設置。
- **聊天配色與頭像框**：勾選聊天壁紙或頭像框時，所選角色使用默認紫色氣泡；頭像框基於 `PRESET_THEMES.default` 生成 `anniversary-frame-<角色 id>` 副本，不沿用舊氣泡主題的配色、貼紙和 CSS。不勾頭像框時直接使用默認氣泡。其他角色及原有共用主題不被改寫，重複應用複用該角色的副本 id。選擇頁會說明主題同步切換。
- **下載後手動使用**：解壓後，通過外觀的壁紙上傳、聊天設置的背景上傳，或氣泡工坊的頭像掛件上傳自行設置。

## 原圖為什麼直接放會偏

頭像框原圖為 1080 × 1440，透明畫布中心是 `(540, 720)`，頭像開口中心約為 `(514, 705)`。默認按頭像寬度、畫布中心放置，大小與中心都對不上。

彈窗預覽和新應用的頭像框使用縮放 `1.6`、X `53.9%`、Y `52.2%`、旋轉 `0`，比之前的 `1.8` 縮小約 11%，讓裝飾環卡在頭像圓邊上。頭像在使用此框時裁為圓形。下載包內的手動設置參考也使用這組參數。用戶已保存的掛件尺寸不會被自動覆蓋。

工坊預覽、私聊和群聊通過 `avatarDecorationImageStyle` 共用定位；用戶上傳的其他掛件仍沿用原來的默認值。
