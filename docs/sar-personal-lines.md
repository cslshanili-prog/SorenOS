# SAR 個人線

當前實現核對：2026-09-12。用戶操作總覽見 [SAR 活動室怎麼玩](./sar-user-guide.md)。

常駐 NPC 關閉時，名冊、專屬紀念、NPC 專屬圖鑑條目以及角色稱號顯示和編輯全部隱藏，運行中的個人線與尚未投遞的彩蛋暫停；聊天與活動不注入 NPC 背景或稱號提示詞。進度和原稱號保留，重新開啟後恢復。開關同頁、跨頁即時同步，已關閉後返回的角色活動不能寫入新稱號。舊聊天記錄不刪除。

凱恩與艾文的原稿目前覆蓋一至三星。名冊保留五顆星，四、五星不生成臨時劇情。

艾文普通日常問候按「星期 → 時段 → 天氣」排列，每組仍隨機選一句，同一訪問內保持穩定；星期使用用戶設備的本地日期。

## 日常與回憶

- 點擊常駐 NPC 先進入正常對話；艾文的問候或當前劇情讀完後，再顯示「賣魚 / 離開」，沿用對話選項樣式與收尾立繪，不增加前置菜單。星級事件先單獨顯示結束頁，繼續後再出現賣魚選項。賣魚直接打開自己的魚獲列表，沿用行情、額度、到帳與艾文回執；名冊回看不出現售魚選項。NPC 隱藏時不顯示相關選項，也不主動觸發個人線。
- 兩人分別按用戶本地自然日抽取普通話題：80% 從當前篇章十個未完成話題中選一個，20% 不觸發。刷新、切頁、跨標籤頁不會重抽；時鐘回撥不會額外產生機會。
- 本篇章十個普通話題全部完成後，下次點擊角色才開始星級事件，無需等第二天；完成事件才升星。艾文已開放的星級彩蛋另有每天一次的獨立 20% 抽取，不替代普通話題。「字變了」（A1-E07）必須在「不要再釣了」（A1-E06）完整結束後才會觸發；抽取、舊待觸發隊列、開場與結算均校驗前置關係。Sully 偶遇也獨立檢查在場條件與概率。多段同時抽中時，普通話題優先，其餘保留到後續點擊；已完成內容不重複。三星後只保留原稿已有彩蛋與偶遇，不補寫四、五星。
- 正式遊玩沒有對話返回按鈕；切走導致日常話題、星級事件和彩蛋中斷後不算完成，下次點擊從同一段開頭重來，分支、表情與互動草稿重新開始。未讀完的普通話題跨天重開也佔當天話題名額。普通話題和彩蛋讀完直接回房間；星級事件讀完最後一句後，再點擊才結算並進入獨立結束頁，顯示「結束 X 星事件：標題」，保留末句表情，點擊再離開，沒有追加話題菜單。無事件時按時段、天氣與星期抽取問候，逐句讀完也直接退出。
- 星級事件完整結束才點亮對應星。Sully 偶遇只在本尊實際加入 SAR 時發生，內置 ID 優先，因此重命名不影響識別。
- 已完成內容收入「隨身倉庫 → 圖鑑 → 名冊 → 回憶」。回看使用獨立內存游標，不寫入進度、不發獎、不續限時優惠、不再發送私聊彩蛋。

名冊的「人物檔案」保留兩人完整原文簡介；回憶按星級事件、日常話題、彩蛋與遇見分組，未完成項只顯示通用鎖定標題。名冊是用戶與這兩位 NPC 的進度，不隨倉庫切換到哪個角色而變化。回看返回名冊；收藏、專屬紀念、名冊共用「收集圖鑑」標題與三個固定標籤，只切換下方內容，不另開層級。詳情返回當前標籤列表，標籤根頁返回隨身倉庫。

## 對話與鏡頭

個人線默認單人居中，另一位 NPC 實際發言後進入雙人同框，並留到當前對話節點結束（包括接話和反應）。跨節點檢查後續六句：仍有對方台詞時保持同框，沒有則恢復單人；選擇尚未確定時，只保留已出場的人，不提前引入未出場角色。台詞提及名字、設定聽者表情不會觸發首次出場。`guestPresent` 與原有游標一起保存，同一次閱讀與回放遵循同一規則。凱恩初遇也使用這套留場規則。初遇中凱恩被拆台的 embarrassed 表情在他接下一句時觸發。

取消對話頂部信息欄，人物名、星級集中在底部名字行；返回按鈕只在名冊回看顯示，正式劇情與初遇隱藏；話題標題也放在這裡，但僅在名冊回顧時顯示。初遇與日常統一為淺色全屏舞台，不留上下黑邊；底部為固定高度的氣泡，點擊按句推進；時間、天氣、星期問候也逐句顯示。當前原稿台詞讀完才推進存檔游標，句內分頁不改變分支與獎勵。讀到選擇點後，選項使用與當前界面同色的居中浮層，聚焦與懸停不改底色，不佔底部佈局或改變立繪大小。單人、雙人、普通問候共用按舞台高度計算的縮放，兩人統一縮小 15%，下緣與對話框對齊，不再額外下移。互動演出完成確認後才顯示選項。

證件、合照、物品或恐龍等演出保持完整立繪與底部對話，物品只在對應的展示台詞上進入立繪前方，點擊繼續後收起。`effectLine` 指定展示的原稿行（默認首行），未拿出物品時不搶先展示；展示行若接選項，先收起物品，再居中呈現選項。照片和成員證完成操作後才允許繼續。收藏頁仍可完整查看物品。玩家可隨時離開，下次從這一段開頭重新閱讀。個人線來自固定原稿，不調用世界意志或 LLM 續寫，與五十輪芯片演繹分別保存。

## 獎勵與演出

劇情和獎勵存於 `vr_fishing_market_v1.sarFamiliarity`，與錢包、模塊、魚獲使用同一個加鎖事務。本次閱讀經過的節點先記入 `visitedNodes`，完整讀完後統一結算進度和獎勵；中斷重開丟棄本次未結算的節點。每個已發獎勵的節點保留唯一記錄，重複點擊和跨頁競爭不會重複發放；舊檔已入庫的贈品保留並跳過重複發放。存儲失敗時整筆回滾。

- 凱恩：管理員證演出；經用戶確認的成員證；隨分支保存結論的會議記錄；可調構圖、縮放、取景、加入自家角色的合照；帶用戶標籤的舊式存檔卡。
- 艾文：貓科語法包、關鍵詞消音器、隨機標準恐龍、恐龍蛋、優惠券、隱藏稱號、備用存檔卡與專屬 `aiven-chimera`。
- 三星物品堆是演出道具，只有明確贈送的物品入庫。假稱號、七折玩笑、加載失敗提示也不產生真實資產。
- 券雨固定三張；禮炮、物品爆出和恐龍展示通過普通對話繼續，不額外要求確認。成員證、拍照和神秘按鈕保留實際操作。
- 折扣採用 30 分鐘有效期：全店或當前貨架隨機一個商品八折。九折券按真實數量使用；不疊加，自動選擇最佳單項，同價優先用限時折扣以保留券，金額向上取整且最低 1 鱗幣。過期舊報價不會靜默漲價扣款。
- 新檔稱號系統於艾文二星開放，獲得的「聽懂風的人」可在稱號編輯器選用，不覆蓋用戶已有稱號。舊檔已有稱號保留使用資格。
- 蛋由艾文三星話題送出並開放對應圖鑑，退出隨機垂釣池。舊檔已有的蛋和歷史收藏保留。專屬混合恐龍不進入垂釣、普通隨機贈禮或孵化池。
- Sully 彩蛋進入本地私聊消息隊列，以固定投遞 ID 去重，不調用模型。

## 素材與保存

17 張表情來自用戶提供的 [SAR 素材倉庫](https://github.com/qegj567-cloud/SullyOS-assets/tree/main/SAR)。凱恩支持 11 種、艾文支持 6 種合法表情；逐句選擇，旁白保留上一個表情。凱恩新增 `Enduring Pain`（忍痛，原名含空格）、`avoidant`（迴避）、`normal2`（平常2）、`warm`（溫柔），可手動校對並隨草稿、清單導出，已將 2026-09-12 用戶校對清單寫回原稿。`public/sar-portraits` 保留原畫布比例，轉為最大邊 1500 px 的 WebP，合計 3,190,522 B（約 3.19 MB），原有 13 張素材及其透明信息保持不變。新增四張已同步素材提交 `01edb974` 的透明 PNG，重新生成 WebP 並更新緩存版本；既有表情標記保持有效。本地加載失敗時回落原 CDN。

紀念物保存當時的姓名、日期、圖片引用、構圖和選擇；後續更換形象不修改舊照片。在「倉庫 → 圖鑑 → 專屬紀念」單獨查看證件、照片、會議記錄、存檔卡與劇情專屬恐龍，可按凱恩／艾文篩選，每頁最多十二份；只展示真實獲得的記錄，轉出的特殊恐龍仍保留歷史收錄。凱恩紀念物使用紙頁、壓印、相紙與舊式存儲卡外殼的統一呈現，收藏縮略圖為輕量靜態物件，不運行劇情或 3D。倉庫的「紀念」仍可打開同一份原物，「優惠券」顯示真實未使用數量；它們不借用當前查看角色的錢包或背包。

完整 ZIP 的 `sarLocalState` 包含個人線與未完成草稿，嵌套 `blobref:` 經元數據掃描一併導出二進制圖片，恢復時沿用原 token。純文字備份剝離 `blobref:` 和內嵌圖片，保留進度、紀念物文字、構圖、分支、優惠及投遞狀態。備份包含獎勵收據，因此恢復後繼續閱讀仍不會重複領獎。

### 本地校對入口（默認關閉）

回顧左上角常駐「返回選項」，直接回到最近一次選項前，重選另一條分支；還沒有選過分支時顯示「返回上一步」。無需展開表情校對欄。分支結束後臨時保留結束畫面，仍可返回選項，點擊對白才離開回顧；已保存的表情修改不會被回退。

`pnpm dev` 下先打開扳手，開啟「SAR 劇情與表情校對」，「圖鑑 → 名冊 → 回憶」才臨時開放凱恩、艾文的全部 84 段原稿，包括話題、六個星級事件、彩蛋和偶遇；四、五星沒有原稿，不補出虛構條目。進入回顧後點右上角「表情校對」，可逐句選擇發言角色的表情，灰色聽者只讀並提示跳回其台詞修改，使用「上一句」「跳轉台詞」定位台詞或分支，「恢復這句原表情」只撤銷該句修改。名冊和校對側欄均提供「複製修改清單」「下載修改清單」，導出兩人的全局 JSON，供後續核對並回寫原稿數據。

開關默認關閉，關閉後收藏冊立即恢復真實解鎖狀態，正在看的未解鎖預覽退出；已保存校對草稿仍保留。入口與讀取權限同時受 `import.meta.env.DEV`、調試面板可用性與 `sarExpressionReview` 開關限定；生產構建一律不允許臨時解鎖，正式版手動打開調試面板也不能開啟它。回顧游標、分支、證件確認和拍照草稿只存在內存，不修改星級、獎勵、收藏、聊天或正式備份；離開後從頭測試。表情修改單獨存於按分支隔離的 `sullyos.devDebug.sarExpressionReview.v1.<branch>`，刷新後仍可繼續校對，不改 `sarFamiliarity` 或原始劇情文件，也不加入 SAR 遊戲存檔備份。

`scripts/test-sar-event-preview.mjs` 從真實名冊逐條打開全部 84 段並完整讀完六個星級事件，核對正式市場存檔不變、零模型調用，以及編譯為 `DEV=false` 後全部拒絕臨時預覽。

### 台詞與演出細節

姓名佔位符統一解析為用戶暱稱（兼容 User 大小寫及括號）；發現者記錄、成員證、紀念物和對白共用解析，默認資料名 User 以「你」稱呼，暱稱中的美元符號按字面保留。

SAR 陳述句統一使用句號，問號、感嘆號、省略號和括號動作保留各自語氣；標題和按鈕不追加句號。用戶清單共 288 處，286 處直接寫回；一處灰色聽者修改遵循新規則，一處收尾修改由用戶最新的開心台詞覆蓋。角色變灰時沿用其最後一次發言的表情，旁白也不換表情；只有輪到本人發言才按原稿切換，不強制按句數換臉。長台詞可用 `sentenceExpressions` 指定拆句後的表情，存檔保留末句表情。艾文拆台時不搶先切換凱恩的 embarrassed，留到凱恩的反應句。

展示物品時可點擊物品或「放大查看」打開獨立詳情，關閉後停在原句，不確認領取、拍照或寫入獎勵。成員證使用正向文字與不參與濾鏡柵格化的容器，確認按鈕在證件下方。艾文的禮炮覆蓋整個視口，有限時長且不阻擋操作，尊重系統減少動態效果設置。
