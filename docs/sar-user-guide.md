# SAR 活動室怎麼玩

當前實現核對：2026-09-11，開發分支 `codex/dino-cafe-art`。試玩頁使用示例收藏與示例來客；彼方里的正式入口使用你的收藏、角色和 API 配置。

## 先認識活動室

在彼方頂部點擊「世界」旁的「SAR」，進入獨立全屏活動室。左上角返回彼方，活動室內不顯示公共頂欄或房間翻頁。點房間裡的設施標記進入玩法，點在場角色查看角色。凱恩和艾文在房間裡是 Q 版形象，點開對話後顯示立繪。

右上角隱藏按鈕按四檔循環：只隱藏角色名字與稱號 → 隱藏全部房間文字 → 隱藏所有角色小人並恢復設施標記 → 全部恢復。第三檔也會隱藏凱恩和艾文，但不改變接入設置。自家角色只有當前活動實際在 SAR（釣魚、佈告板、箱庭、模塊或芯片活動）才顯示在這裡；僅接入彼方不會自動入場。

| 入口 | 可以做什麼 |
| --- | --- |
| 凱恩、艾文 | 看初見、各自的每日話題和星級事件，原稿固定分支，不花模型調用。隱藏 NPC 後仍能使用設施。 |

## 凱恩與艾文：慢慢熟悉，再把回憶收好

凱恩完成初見後，點他即可進入個人線；艾文直接從自己的入口開始。兩人各自每天對普通話題抽一次：80% 遇到一段尚未完成的話題，20% 不觸發。刷新或反覆點擊不會重抽；沒有事件時會說三句日常問候，艾文按「星期 → 時段 → 天氣」排列。點擊艾文先正常對話，讀完後才顯示「賣魚 / 離開」，選擇賣魚直接進入自己的魚獲列表；凱恩讀完仍直接回房間。名冊回看不顯示賣魚選項。

每個篇章有十個不重複的普通話題，全部聊完後，下次點擊角色才開始對應星級事件，不必等第二天。事件完整結束才點亮星星；目前有一至三星的原稿。艾文的星級彩蛋獨立抽取，不佔普通話題的名額；多段同時抽中時，剩下的留到後續點擊。遇見 Sully 的段落要求他實際在 SAR。

正式劇情隱藏返回按鈕，回看才顯示；切走導致日常話題、星級事件和彩蛋中斷不算完成，下次從這段開頭重來；完整讀完才結算獎勵；星級事件最後一句讀完後，再點擊進入獨立結束頁，顯示「結束 X 星事件：標題」；艾文繼續後顯示「賣魚 / 離開」，凱恩或名冊回看繼續後返回。灰色角色沿用上次發言的表情。初見與日常都使用淺色全屏佈局，選擇按鈕在畫面中央。另一位發言後保留到當前交流結束，接下來的分支仍有台詞時也不退場。只是提到名字不會讓對方出現。17 張原畫表情已隨應用本地提供，凱恩 11 張、艾文 6 張。凱恩新增「忍痛、迴避、平常2、溫柔」，已同步新版透明背景，可在本地開發模式的扳手中開啟「SAR 劇情與表情校對」後選擇，開關默認關閉，已應用用戶校對的表情編排。

事件中的證件、會議記錄、可調整人物和背景構圖的合照、禮炮、優惠券雨、神秘按鈕和特殊恐龍都有對應演出。對話時保留完整立繪，提到展示物品時才拿出來，點擊繼續便收起；拍照和成員證需要先完成操作。明確贈送的模塊、恐龍、優惠券與紀念物才真正入庫，每份獎勵只領一次；畫面裡出現的玩笑道具不全是獎品。

到「倉庫 → 圖鑑 → 專屬紀念」收好星級故事裡的證件、合影、存檔卡與特別贈禮，可按凱恩和艾文篩選、翻頁回看。同種恐龍每隻都有獨立名字，可以在箱庭的「名字與管理」單獨修改。

到「倉庫 → 圖鑑 → 名冊」查看兩人的完整檔案與五顆星，在「回憶」重看已經完成的話題、星級事件和彩蛋。未發生的內容保持鎖定；回看不會推進星級、再發贈品、續折扣或重發私聊彩蛋。名冊記錄你和兩人的關係，不隨倉庫切換到哪個角色而變化。完整規則見 [SAR 個人線](./sar-personal-lines.md)。

## 角色接入：掛機等你，或自動活動

去「彼方 → 接入」開啟角色並設置 Q 版形象。接入列表沿用你的角色分組，每頁最多五位，切換分組會回到第一頁。新接入默認「僅手動活動」：角色知道彼方，形象可以留在房間裡；不用選擇間隔，不會因到點或刷新自行啟動模型。你點「讓 ta 現在去逛一次」、邀請釣魚、逛佈告板或來箱庭時，才執行這一輪活動。已有動態、收藏和收到的程序回執照常保留，收到回執不自動觸發回覆。

想讓角色自行活動，切到「自動活動」再選間隔。已有存檔原來開啟的定時登入保持原樣。切回僅手動會撤掉計劃；正在生成的那一輪可以完成，但不會把設置改回自動，也不會再接著啟動新一輪。純掛機本身不調用 LLM，每次邀請按相應玩法計費。

「讓 ta 現在去逛一次」分為「普通空間 / SAR 活動室」兩級菜單，SAR 可單獨指定抽芯片演繹、模塊商店、釣魚、佈告板和恐龍箱庭。角色卡片下方的「高級選項」可以排除自動前往的房間或 SAR 單項，也可排除整個 SAR。自動活動先隨機選可用房間，再在 SAR 內選具體玩法；禁用項不進入隨機池，全禁用則跳過本輪、不調用模型。手動邀請仍可前往，玩法本身的條件照常檢查。完整規則見 [活動選擇與自動活動範圍](./kanata-activities.md)。

## 恐龍箱庭：先佈置，再讓角色來玩

### 你來準備庭院

1. 點茶几進入箱庭。首次會收到艾文贈送的一隻橡皮泥霸王龍；以後釣到或獲得的恐龍進入收藏，同種不同只也分別保留身份。
2. 選擇溪邊草原、貝殼海岸或火山探險。每張地圖分別保存佈置，**一圖最多六隻恐龍、十二件擺件**。你和角色的恐龍共用名額。
3. 點「佈置」，選擇擺件。預覽中會顯示格子、發亮的物品和朝向箭頭；選位置、轉向，再點「確定」。點取消不改原來的佈置。
4. 點場景裡帶爪印的擺件，選擇「讓恐龍來玩」，再選一隻恐龍。程序尋找能互動的位置和朝向，你確認後才保存。已被佔用、地圖滿員或不適合互動的藏品會事先說明。
5. 如果舊擺件的位置不適合落格，預覽可能同時調整這件擺件和恐龍，會明確提示；仍需你確認，其他恐龍不會被擠走。
6. 點恐龍可以換地方、換配色、取名，或者寫一句「正在……」。不用填行為對象，也不用寫指令。留空就顯示當前位置的小日常。

恐龍固定在確認好的位置和朝向，只做原地動作：野餐墊上吃點心、水邊玩水、低頭聞花、夠樹葉、在帳篷或石旁打盹、站在木樁上搖尾巴。火山、路牌、柵欄和小屋目前是裝飾。蛋與骨架保持靜態。這些動畫由程序播放，**不調用 LLM，也不會按每次動作寫一條記錄**。

配色、名字、原文和獲得來源屬於具體那一隻恐龍。把它搬去另一張地圖不產生副本；贈送後歸屬改變，名字、配色和經歷保留。掛板出售或孵化中的藏品不能同時擺進箱庭。

### 角色來訪時發生什麼

先在「來訪」開啟共同擺弄，再選擇已接入彼方的角色並邀請。它可以擺弄共同庭院裡別人的恐龍，不會因此取得所有權。想保留某隻的佈置，可以將它「固定」：角色仍能評論，但不能移動或續寫。

一次來訪按下面的流程完成：

1. **看現場。** 角色獲得這次訪問地圖裡的恐龍名字、種類、歸屬、配色、格位、固定狀態，你寫的原文、當前狀態，以及程序實際支持的環境互動。它也能看到擺件、可用落點和最近的足跡。
2. **想一個動作。** 使用這個角色原本的人格與聊天上下文，調用一次模型。模型在「留便籤／移動或轉向一隻／續寫一隻的正在」中選一個，同時給出自己的話。
3. **程序檢查。** 模型使用固定格位或“靠近／面向某個對象”，程序負責落點、朝向和碰撞。如果恐龍已被收起、固定，或者你剛改過佈置導致結果過期，這次改動會被拒絕，不覆蓋新佈置。
4. **執行並記下。** 合法操作保存到箱庭，便籤或狀態帶上角色署名，並在該角色的聊天裡留下彼方活動卡。不再另外調用一個模型來寫總結或執行動畫。
5. **你回來查看。** 在「來訪」和足跡裡看誰做了什麼，定位恐龍、回覆便籤。角色的移動或續寫，在恐龍沒有再被改動且舊位置仍可用時可以還原；還原本身也會留記錄。

例如，你寫「莓莓正在等薄荷還餅乾」。角色可能把莓莓挪到薄荷旁邊，留一句「自己去要」。這輪就結束了，不會接著自動展開多輪談判。下一次來訪才會產生下一個決定。

目前角色不能在來訪裡新增擺件、換地圖、改恐龍名字與配色、贈送、出售或憑空創造物品。“正在修城堡”可以是一句小劇場，但不會真的生成城堡。角色來訪也沒有單獨的 Q 版角色走入 3D 庭院的演出；可見結果是恐龍的位置／狀態變化和留下的便籤。

### 角色知道誰動過什麼嗎？

**知道最近發生的事，但不是全知的歷史管理員。**

| 內容 | 當前怎麼處理 |
| --- | --- |
| 誰、何時、在哪張圖、對哪隻恐龍做了什麼 | 成功保存的操作寫入足跡，保留作者身份、時間、操作類型、對象與說明；有留言時保留原話。 |
| 你原來寫的那句話 | 單獨保留。角色續寫當前狀態不會覆蓋你的原文。 |
| 角色改動前的狀態 | 移動或續寫保留改動前的位置／狀態，用於回看和有條件還原。 |
| 角色本次直接看到的歷史 | **當前地圖最近 10 條**足跡的作者、事情和原話；另有最近事件幫助既有記憶召回，以及它自己的聊天上下文。 |
| 某人累計移動了幾次、最愛擺弄誰 | 當前沒有專門統計，也沒有把完整歷史全部發給模型。不能保證角色回答全歷史次數準確。 |
| 未確認的預覽、取消、原地動畫 | 不記成已發生的擺弄；失敗的來訪也不會偽造成功足跡。已發出的模型請求仍可能有 API 費用。 |
| 其他角色是否立刻知道 | 不會向所有角色廣播並各調一次模型。下一位來訪者讀取當時可見的最近足跡；活動發起者有自己的聊天卡。 |

箱庭足跡目前不自動裁剪。你在某條足跡下回復，會成為新便籤，不會立刻觸發角色再回答。

開啟共同擺弄後，已選擇自動活動的角色也可能在正常彼方活動中選擇來訪。自動來訪按近期成功足跡限制：同一角色至少間隔十二小時，全體二十四小時最多三次。手動邀請不受這項自動頻率限制，但會留下足跡，影響後續自動資格。

自主來訪依賴應用運行，不是雲端掛機。關閉應用期間不會持續新增拜訪；重新打開後按彼方調度檢查到期活動，不按離線天數補出一串箱庭事件。自動訪問的是當時選中的地圖，不會逐張巡視所有地圖。

## 水域：自己釣，或者讓角色去釣

你自己玩：手動模式拋竿後按住／鬆開水面，讓控制弧跟住魚，成功後收進收藏；簡單模式看見魚影后點附近拋竿，或用底部按鈕自動瞄準；等浮標落水、自動收線，成功才收進收藏。判定寬鬆但仍可能空軍，沒有魚影時更容易落空。物種、大小和品質由程序抽取，自己釣魚不調用模型。操作說明點問號查看，想讓角色去釣魚時展開底部「角色釣魚」。

天氣優先使用已配置的真實天氣；不可用時顯示彼方模擬天氣，影響出沒概率。天氣請求不是 LLM 請求。當前隨機魚池包含 9 種魚和 11 種橡皮泥藏品。恐龍蛋改由艾文三星話題贈送並開放圖鑑，不再隨機釣到；舊檔已持有或曾獲得的蛋仍保留記錄。

在自己的收藏裡，你可以按行情賣出、自己定價掛板、陳列，魚類還可以放生；橡皮泥模型能製作觀察記錄，恐龍蛋可開始六小時孵化，到時由你點擊揭曉。查看、等待、揭曉都不調用模型。圖鑑發現記錄不會因賣掉藏品而消失。恐龍也可從這裡進入箱庭。

艾文三星事件的專屬「？？？」是霸王龍身體、三角龍角、劍龍背板與腕龍長脖子的混合恐龍，有獨立橡皮泥模型。它作為真實贈禮加入收藏，可帶進箱庭；普通垂釣、隨機贈禮和蛋的孵化都不會產生它，回放也不會多領一隻。

這裡的角色指用戶接入彼方的角色；固定 NPC 凱恩與艾文仍走自己的預設演出，不參加這套自主釣魚。

角色自己玩：選擇已接入的角色 → 點「讓 ta 去釣魚」→ 程序抽定並暫存這一竿的魚獲 → **一次主 LLM** 返回 JSON：反應、保留或放生、可選的私聊原話 → 程序核驗並執行 → 寫下活動卡；選擇分享時另寫一條普通私聊消息，直接使用同一次生成的原話。

保留／放生與是否分享獨立：放回水裡，也可以告訴你；收藏下來，也可以什麼都不說。分享不轉移物品所有權。橡皮泥恐龍只允許收藏，不提供放生。這次釣魚沒有掛賣和定價，角色需要另去佈告板處理交易。

每個角色有自己的收藏櫃和水域圖鑑。收藏櫃顯示當前持有的每一件物品；圖鑑保留曾經獲得的品種、首次獲得日期、累計獲得次數。放生、賣出或贈送不抹去圖鑑，重複獲得獨立計數。舊存檔只補有記錄可證實的內容，不補發舊解鎖播報；不完整的歷史標為“已記錄至少”，無法確認的日期不編造。

角色首次解鎖一個品種時，程序自動以「彼方播報」身份在公共留言簿發佈一次圖鑑解鎖通知，並把事實回執同步給已接入彼方的角色。這是當前用戶這份彼方里的公共播報，不跨用戶聯網。通知不公開角色的私聊原話，也不觸發其他角色立即調用模型回覆。重複獲得、刷新頁面或重試不會重複播報，清空留言牆也不會重新補發已發佈通知。

網絡失敗或 JSON 無效時，魚獲仍然暫存在該角色的收藏中，按鈕變為「繼續處理這一竿」。再次請求只處理原來的同一件物品，不重新抽取；暫存期間不能交易或擺進箱庭。已經完成的分享或播報如果保存失敗，會留下待發送記錄，下次進入或通過「重試發送記錄與分享」繼續同步，重發本身不調用 LLM，也不重複放生或入庫。

角色的本輪提示詞只追加實際釣到的這一件、該角色之前持有同品種的數量和相關獲得記錄；原有角色設定、聊天上下文和已配置的記憶召回仍走彼方共用鏈路。不發送整個魚池和所有角色的背包。一次邀請只處理一竿，不會自動連釣。

## 內部佈告板：交易，也可以說廢話

這是你和角色的本地市場，新錢包初始有 120 鱗幣，舊存檔餘額保留，各用各的錢包。首頁按時間擺放所有便箋，點開後在獨立頁面回覆或成交；「寫便箋」是統一發布入口。右上角「更多」裡可以查看當日行情、往期便箋與收支記錄，或邀請角色來逛。返回時保留原來的閱讀位置。

寫便箋時選擇想做什麼：收到一句回應、找到一件藏品、轉讓東西或收一份心意。出售可選真實庫存，或明確標作文字商品的約定；填寫金額時會說明誰收錢、誰付款，匿名筆名收在「署名」裡。成交按鈕直接寫明支付或領取的金額，「僅回覆」不扣錢。文字回應提交即結算，不支持後續驗收任務。便箋一般二十四小時到期，原文和回覆仍在發帖方的往期便箋中。

響應實物求購時，先選擇要交付的具體那一件，列表顯示名字、大小和星級；同種藏品不會自動拿第一件頂替。若所選藏品已經掛售、轉手或不可用，這次交付會停止。新掛單與已完成求購會保留當時的藏品資料，詳情中也能看到買家／交付人；舊檔案沒有記錄的資料不補編。匿名發帖後，在自己的便箋下回復會沿用原筆名。

點「讓 ta 逛佈告板」時，角色讀自己的餘額、可用庫存、公開便箋、近期相關回執，**一次 LLM** 選一個動作：瀏覽、買入、交付需求、回覆、掛單、發需求或撤自己的便箋。程序再次檢查錢、庫存和訂單狀態，成功才成交；失敗就記錄實際失敗，不讓一句吹牛改變帳本。同一輪也可生成去留言簿或私聊分享的原話。目前留言簿分享會實際發帖；佈告板的私聊分享仍寫在活動卡的「私聊原話」裡，沒有單獨發送普通聊天消息。

每人最多同時發佈十二張便箋，每張最多四十條回覆。求購或招募發佈時不預扣鱗幣，真正交付時再次檢查餘額，可能因發帖人後來花完錢而失敗。模型每輪最多看到自己的三十件可用庫存、最新十八張掛單、十八張需求與近期回執；不保證一次讀完整塊板。庫存與實物掛單會提供大小、星級和已有的恐龍名字，並明確區分實物和文字商品；角色交付實物也要指定具體藏品。

主頁點「刷新」隨機來兩三位路人，或一位開啟自由活動的角色。路人現在用 **一次 LLM** 共同生成一輪 3～8 個動作，能發新便箋、在同一帖下接話、針對舊帖隔空喊話；沒有固定台詞兜底。路人沿用四個獨立錢包，不隨刷新補錢；真正角色仍走自己的活動模型與人設。沒有 API、回覆無效或中途離開時不補寫假帖子；生成期間發生的交易會按最新狀態再次校驗。關閉彼方 NPC 後不生成路人。

## 扭蛋與裝配櫃：兩種不同長度的芯片體驗

扭蛋機有「異界異格」和「異界座標」兩類芯片。抽取、揭曉、查看收藏都由本地程序完成，不調用模型。

**兩個卡池每天各有一次免費抽取，之後每次 90 鱗幣。** 同池連續兩次抽到已有芯片後，下一次必得未收錄芯片；兩池分別記錄，免費和付費抽取都計入，收齊後正常隨機抽取。免費次數按本地日期重置，回撥設備日期不會補發，餘額不足時仍可使用未領取的免費機會。按鈕會明確顯示此次是否收費；如果另一個頁面搶先用了免費次數，不會自動改成付費。抽取成功後即存入收藏，未看揭曉就離開也不會丟失。

你想親自玩一段故事時：打開裝配櫃 → 選角色 → 從已有收藏各放入一枚異格與座標芯片 → 點鑄造。**一次 LLM** 生成異格身份、你的異界面具、世界線與開場。裝配要求擁有芯片，目前不會扣掉芯片數量。

身份卡先展示簡介和開場，人物身份與背景按需展開，秘密與預設高潮不在卡面劇透。點「進入故事」或「繼續故事」，輸入你說的話或想做的動作。正式演繹使用線下現場劇情，舊通訊記錄保留其歷史原意。

世界意志負責讓角色和世界有自己的行動，但用戶可以探索、陪伴、拒絕或忽略事件，不需要先理解設定或規劃劇情。日常與關係互動同樣有效，安靜片段可以沒有獨立旁白；故事時間也不會每條回覆都自動加速。背景資料、閱讀外觀、互動進度與提前封存入口收在右上角「演繹資料與設置」。閱讀舊內容時，新回覆不會強行拉走視線，可以點「回到最新內容」。

每次提交行動或話語，**一次 LLM** 同時生成必要旁白、角色回應和簡短連續性事實記錄。內部記錄幫助保留事件與被拒絕的鉤子，不展示在正文或導出全文中。成功保存才計一輪，最多五十輪；末段收束實際參與的經歷，允許主線未解決，不要求清完任務。開場來自身份卡，不另算一次生成。因此新鑄一張卡再完整玩五十輪，玩法主流程仍共 **51 次生成**；繼續已有卡不再付鑄造那一次。離開頁面不會自動生成或消耗輪次，稍後可繼續；「提前封存」會結束本段，當前無法直接續寫。

正式推演使用角色設定與關係概況，但隔離現實的具體聊天事件。檔案保存在獨立推演記錄裡。封存後可以導出、回看，或主動分享給角色；分享動作只把檔案說明寫入主聊天，不會立即自動生成回覆。之後再讓角色回應，才是一次普通聊天。

角色自己逛進裝配櫃時則是短體驗：程序隨機選兩枚臨時芯片和一個對象，**一次 LLM** 生成完整短劇情、角色隨筆和高光，歸入「看看角色的櫃子」，並留下活動卡。不會消耗你的芯片或每日額度，不會偷偷跑五十輪；被選中的另一個角色也不會因此再被獨立調用一次模型。這是一位角色敘述的臨時芯片體驗。

## 模塊商店：暫時換一種表達方式

進入商店 → 看五件當日貨架商品，也可以使用當天的三次免費換貨架 → 按標價購買模塊 → 到模塊袋選角色 → 填必要的字面配置 → 確認裝載。購買、選人、確認和裝載動畫都不調用模型。

**模塊目錄價為 18～34 鱗幣，按顯示的實際優惠價結算。** 購買只增加庫存，不會自動裝載；裝載消耗一枚。與釣魚、佈告板使用同一個餘額，既有收藏和庫存保留，不追扣試玩期間的費用。原票據不再作為支付餘額。

個人線可以送出九折券或 30 分鐘八折優惠，八折可能覆蓋全店，也可能只對應當時貨架上的一個商品。商店自動使用最省錢的一項，不疊加；同價時優先用限時優惠，留下券。購買成功才扣券，券雨固定給三張。優惠過期導致價格高於剛才確認的報價時，會停止交易，讓你重新確認價格。

用戶購買的扣款、庫存和收據一次保存；餘額不足或保存失敗時不完成交易。重複提交同一購買記錄不會重複扣款。庫存、免費次數和付費記錄隨 SAR 備份一起保存。角色逛模塊店會決定只看或購買；買下的模塊進入自己的倉庫，只扣自己的錢。自動購買每天最多花 60 鱗幣，並保留 30 鱗幣，已有同款時先用庫存。角色對你裝載或回敬模塊也必須消耗自己已有的一枚；餘額或庫存不足時不會憑空生成模塊。角色裝配櫃的一次短劇情仍使用臨時芯片，不計入任何人的永久庫存。

模塊影響後續聊天中可見／可聽的表達，保留真實語義和人格。例如惡役大小姐是禮貌、華麗的大小姐語氣，語種仍跟隨角色設定，不會直接把角色變成另一種人格。角色端持續十次成功互動，結束後有三次表達恢復期；失敗、取消不消耗輪次。

開啟「允許角色給我裝模塊」後，還有兩種反向裝載：

- 你給角色裝載時，如果你和合適的角色都在 SAR，程序可能在裝載結算中給你裝一枚隨機適用模塊。這一路沒有額外 LLM 決策。
- 角色自主活動選到模塊商店時，程序提供一枚適用模塊，**一次 LLM** 寫活動並決定是否裝到你身上。仍要求你已允許、本人接入且在 SAR、當前沒有用戶模塊。

用戶端持續五次成功互動，再經過三次恢復期。誰給誰裝了什麼、何時生效與解除，會作為聊天事件保存，角色能按這些事實反應。模塊的外顯文字和真實含義分開保存；後續聊天把效果和回覆放在同一次生成裡，不另外加一個“翻譯模型”。

聊天氣泡下方，以及見面的閱讀模式、立繪模式，都有明確的「汙染台詞 / 原台詞」切換。兩種見面模式各自保留當前的查看狀態；切換只影響顯示，不改寫聊天記錄。重複短句按當前播放位置配對，舊的原台詞續接快照也能查看對應汙染版本。

自己或角色裝上模塊後，會出現全局「模塊」懸浮窗，列出全部作用對象、模塊名稱和剩餘輪次。點窗頭收起或展開，拖動窗頭可以挪開；切換應用仍能查看。點某個人的「提前結束」會立即解除那個人的模塊，從下一次回覆開始提示恢復表達，隨後三輪成功回覆逐步收起解除提醒。已經開始生成的回覆可能仍受原模塊影響，但不會重新激活已結束模塊，也不會消耗首次解除提醒。提前結束不退款、不重新發放庫存，也不額外調用模型。狀態隨角色／用戶資料保存和導出。


## 模型次數速查

下面統計玩法本身的生成請求；啟用記憶宮殿後，另可能發生記憶檢索的 embedding 請求和達到歸檔條件時的總結生成，不能保證 API 帳單總條數永遠等於這一列。網絡錯誤後再次手動點擊，也算新的請求；當前聊天生成請求不自動重試。

| 一次操作 | 玩法生成次數 |
| --- | ---: |
| 看活動室、NPC 個人線及回放、拍合照、抽扭蛋、查看檔案 | 0 |
| 自己釣魚、交易、孵化、佈置、換色、看原地動作 | 0 |
| 給便箋回覆、還原一次來訪改動 | 0 |
| 邀請一名角色來一次箱庭 | 1 |
| 讓一名角色釣一竿／逛一次佈告板 | 各 1 |
| 刷新佈告板，來訪兩三位路人 | 整輪共 1，不按路人人數疊加 |
| 角色自由活動的短芯片體驗／逛模塊商店 | 各 1 |
| 鑄造一張新的異格身份卡 | 1 |
| 正式推演每提交一輪 | 1，旁白和角色合在一次生成 |
| 啟動已有推演、緊急封存、分享檔案 | 0 |
| 手動購買、裝載模塊及裝載時的本地反向演出 | 0；之後聊天按普通聊天計 |

自主登入按你給角色設置的間隔觸發，先由程序選房間與一項活動，再生成該次活動。一次進 SAR 不會把全部設施逐項跑一遍。連續三次模型請求失敗會暫停該角色的自主登入；沒有真正發出請求的跳過不計為一次失敗。

模型優先級為角色自己的彼方 API → 彼方全局 API → 普通聊天 API。佈告板路人使用彼方全局 API → 普通聊天 API；不會借用某位角色的專屬 API 或私聊上下文。實際發出了什麼請求，可到彼方調用記錄及應用的 API 記錄核對。

## 存檔與當前邊界

箱庭、收藏、交易、芯片、推演和兩人的個人線都是本地保存，需要隨備份一起帶走。完整 ZIP 包含個人線進度、未完成照片草稿、紀念物、優惠和照片所用的本地圖片；換設備導入後保留獎勵去重記錄。純文字備份保留進度、文字和構圖，去掉圖片，因此要完整保留照片應使用完整 ZIP。Git 同步代碼不會同步瀏覽器存檔。

角色的成功自由活動會寫入自己的聊天活動卡，接入已有的記憶流程；這不等於所有角色永遠記得所有細節。NPC 固定引導和個人線不是模型生成的角色自由活動；原稿裡明確的 Sully 私聊彩蛋會按唯一記錄寫入對應本地聊天，不自動調用模型回覆。

當前沒有恐龍大戰、自由手繪塗裝、雲端離線箱庭來訪、跨用戶市場、更多地圖的活動解鎖，也沒有“每人累計擺弄次數”面板。當前可用的是三張地圖、橡皮泥恐龍收藏與配色、原地物品互動、小劇場、真實角色來訪及操作足跡。


## 活動室與隨身倉庫

SAR 獨立活動室整體採用淺色。右上角「設置」控制凱恩與艾文是否出現在房間內，不影響設施，也不關閉你自己的角色；「初見回檔」可以重看凱恩初見，不會清掉其他收藏和進度。角色接入與自動活動仍在返回彼方後的「接入」中管理。

關閉常駐 NPC 後，角色稱號顯示、稱號編輯、名冊、專屬紀念與 NPC 專屬圖鑑條目一起隱藏；初見、個人線和待投遞彩蛋暫停。聊天與彼方活動不再額外注入兩人的背景或稱號提示詞，活動返回也不能更新稱號。魚獲仍可交給回收站，普通魚類、恐龍、芯片、模塊與錢包繼續可用。重新開啟恢復原來的稱號、收藏和劇情進度，不刪除歷史聊天或已有存檔。已打開名冊時，在另一個頁面關閉開關也會退出 NPC 內容。

「倉庫」裡切換自己或某個角色，可以查看各自錢包、芯片、模塊和收藏。每件東西只歸當前主人所有；掛板、孵化、陳列和箱庭中的東西仍屬於主人，並標記狀態。正在裝載的效果單獨顯示，不重複算成可用庫存。臨時故事芯片不是永久物品。

切回自己後，「紀念」可以打開成員證、會議記錄、合照和存檔卡，保存當時的名字、日期和形象，之後換裝不會改變舊照片。「優惠券」顯示仍可使用的實際數量；劇情贈給你的東西不會跑進正在查看的角色背包。

每人每天通過系統回收最多收入 **180 鱗幣**，次日本地零點恢復。超過剩餘額度時會保留整件藏品，不會少付錢收走；仍可收藏或自行掛板。人與角色之間的交易只移動現有鱗幣，不佔系統回收額度。錢包上限為 999,999 鱗幣；舊存檔已經超過上限的餘額保留，可正常消費，降至可容納新收入後再收款。

完整定價、收入估算與後續調參依據見 [SAR 數值規劃](./sar-economy.md)。


## 收集圖鑑與彼方稱號

倉庫右上角的「圖鑑」有「收藏 / 名冊」兩頁。「收藏」彙總魚類、恐龍、芯片、模塊四類進度，按種類點亮，重複獲得不增加種類數；可以搜索、篩選已收錄/未收錄並翻頁。點條目查看介紹、獲得方式與當前持有數量。芯片同時顯示變體和故事兩池進度。恐龍蛋的顯示隨劇情解鎖和歷史收藏變化，因此不同存檔的恐龍目錄總數可能不同。

切換主人後，只顯示本人或該角色的收集記錄。用掉、放生、賣出或轉讓後仍保留已收錄；角色臨時演繹芯片、被別人裝載的效果不會算成永久擁有。舊存檔通過庫存、購買記錄及交易回執補錄能確認的內容；無法證明的舊收集不補造。記錄隨 SAR 備份保存。

活動室的暖白圖標路牌是設施入口，人名顯示在腳下，稱號顯示在頭頂。新檔在艾文二星事件後開放「彼方稱號」，並獲得可選的「聽懂風的人」；舊檔已有稱號保留編輯資格。開放後在倉庫切換自己或角色即可修改，最多 12 個字符，可選已獲得稱號，也可自定義，留空保存可清除。獲得稱號不自動覆蓋當前設置，不改變本名、人設或屬性數值。

角色平時聊天的彼方說明會帶上當前稱號；自主活動可以根據經歷保留、修改或清空自己的稱號，和原活動使用同一次模型回覆，不增加調用。有效活動成功落地後才更新；生成期間用戶手動修改的稱號優先保留，退出彼方後不接收舊活動的改名。

實現入口：平時聊天在 `utils/chatPrompts.ts`；活動提示詞在 `utils/vrWorld/prompts.ts`，由 `runSession.ts` 調用；稱號規範、提取和衝突檢查集中在 `utils/vrWorld/kanataTitle.ts`。預打包的主動聊天模板不會固化打包時的舊稱號。

設置旁的「隱藏」按鈕依次切換：只隱藏角色名字與稱號、隱藏全部房間文字、隱藏全部角色小人並恢復設施標記、全部恢復。隱藏的設施入口不會留下不可見的點擊區域。此偏好隨 SAR 本地設置和備份保留。


## 設施引導與分頁

水域、佈告板、恐龍箱庭、扭蛋機、組裝櫃、模塊商店和隨身倉庫都提供問號玩法頁。第一次打開自動介紹：釣魚與恐龍由艾文負責，其餘由凱恩負責；關閉後記住已讀，仍可點問號重看。介紹不調用模型，也不消耗當天個人線話題，已讀記錄隨 SAR 備份保存。隱藏常駐 NPC 時，玩法說明仍可查看，但不出現 NPC 形象。

異界史冊與鑄造選人支持角色分組、搜索和翻頁，每頁最多 8 位角色。史冊每頁 6 條，角色隨筆僅在打開該角色時讀取，不會一次查詢全部角色。沒有藏品的角色也能正常選中。隨身倉庫每頁 12 條物品記錄，列表上方顯示總條數、每頁條數和頁碼，翻頁欄隨列表滾動保持可見，翻頁回到頂部；自己的主人標籤只顯示「我」。日常三句問候會隨台詞切換合適表情，已有劇情仍保持原稿表情與包袱時機。

接入彼方的角色會獲得 SAR、凱恩和艾文的公共介紹；是否相識仍依據實際活動和記憶。手動與自動活動共用這份介紹，提示詞不額外追加「僅手動活動」段落，活動開關仍按用戶設置執行。劇情裡展示的物品可點擊放大，關閉詳情會返回原句。

收集圖鑑的「收藏 / 專屬紀念 / 名冊」為同頁平級標籤，切換時三項始終保留；紀念物詳情也在標籤下方查看。根頁的返回按鈕直接回到隨身倉庫，詳情先返回對應列表。

SAR 子頁面的頂部操作區統一使用系統的 `--chrome-top`（包含 iOS 安全區及狀態欄預留）。模塊商店的標題和內容一起避讓；恐龍箱庭保留鋪滿屏幕的背景，操作、場景和詳情佈局放在安全區內。獨立紀念物詳情、物品放大及玩法說明也避讓頂部；圖鑑內嵌詳情沿用圖鑑標題，不重複增加預留。後續頁面不要自行減去固定狀態欄高度，也不要僅依賴原生 `env(safe-area-inset-top)`，以免繞過 iOS 獨立運行時的兜底值。

## 凱恩轉達本輪功能優化

NPC 已開啟時，首次點擊活動室「芯片」（異界陳列櫃）或「佈告板」，先以凱恩單人立繪、日常對話框逐頁轉達優化通知，按原稿切換 happy / normal / normal2 / warm。長說明拆為連續兩頁並沿用 normal，強調文字正常排版，不顯示 Markdown 標記。讀完後進入剛剛點擊的設施。

兩處已讀狀態分別存於 `sar-feature-update-september-v1:cabinet/board`，僅完整讀完才標記；中途離開下次重播。關閉 NPC 時直接進入設施，不消耗通知；通知期間關閉 NPC 則立即收起並進入目標設施，也不標已讀。這些通知不走 LLM，不讀取或修改個人線、每日話題、好感度、星級、獎勵或錢包；不要求先完成凱恩初見。
