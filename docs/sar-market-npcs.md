# SAR 佈告板路人群像

佈告板「刷新」保留隨機遇到兩三位路人或一位自由活動角色的入口。路人不再使用固定句庫或本地隨機交易腳本，而是每次前台刷新共用一次模型調用。自家角色仍通過 runVRSession 使用原有人設和上下文；不把自家角色交給路人群像模型代演。

## 一輪流程

1. 從四個有限結算錢包中抽兩三個槽位。模型通過 `personas` 生成臨時路人的姓名與身份；有未封存帖的槽位保持原人物，新人物不重置錢包，老帖保留當時姓名。讀取公開的最新 24 張展板便箋、每帖最近 8 條回覆、5 張近期封存便箋、當日行情與餘額和可用庫存。沒有導入角色私聊、人設或用戶私人資料。
2. 使用彼方全局 API，未配置則跟隨聊天默認 API；不借用某角色的專屬 API。一輪返回 3～8 個有順序的動作，不按路人人數調用多次，也沒有後台刷新計時器或自動重試。
3. 路人可免費發便箋、回覆已有帖子、回覆本輪新帖、買入、交付、掛單、發需求或撤自己的便箋。每人最多一次非回覆動作，可以多次接話。新帖用 n1～n8 臨時引用，後續回覆映射到實際新帖 ID，所以一輪裡可以互相喊話。
4. 先嚴格解析身份、動作、金額和前後引用，再在市場寫鎖內重新讀取最新存檔。金額、歸屬、掛售容量、回覆容量和到期狀態繼續沿用原市場執行器。過時的動作跳過，依賴它的新帖回覆也跳過；有效部分一起保存，界面顯示跳過數量。完全無法執行則不落庫。
5. 來訪調用記錄寫到彼方 API 記錄，顯示「佈告板路人（整輪）」。交易相關的自家角色仍能收到真實事件回執，路人不能直接替用戶發言、付款或決定自家角色的回覆。

## 路人短事件

`encounter` 動作在同一次生成中寫出公開 `title/words` 與隱藏 `event.story`。`mode=buy` 是玩家支付標價，`work` 是路人支付酬謝，`free` 只允許零價。按原掛單/文字需求結算，不新增實體物品、額外獎勵或第二次模型調用。故事建議 80～240 字、2～5 句，有具體細節與短小落點；題材自由，避免套用固定案例、長篇任務與每帖強行昇華。臨時 NPC 不冒充用戶角色或常駐 NPC。

用戶打開帖子只看到招牌，買下/接活後就地展開故事；參與過的帖子收入自己的「往期便箋」。角色上下文收到帖子和預寫事件，可選擇一帖並給出 `REACTION`；程序成交成功後才展開 `{{participant}}`、記錄反應，並通過既有活動卡片和事件回執保存。餘額不足、到期、已被買走不會記錄事件或反應，回覆帖子也不會觸發。用戶和角色共用一次性成交邏輯，重複參與不重複扣款或發錢。

其他 NPC 只能看到事件帖的公開部分，不會代替用戶或角色買走。新一輪可讀取近期已完成事件寫偶爾的後續或關聯視角，未觸發故事不會作為既成事實傳給路人模型。數據隨現有 SAR 備份保留。

## 數值與退出邊界

四個結算錢包各自僅有一次初始餘額，不刷新補錢，臨時人物換名也不重新領錢。沒有可用庫存的路人可得到一件程序抽出的候選魚獲，只在模型確實選擇掛售且掛售校驗通過時寫入；模型不能自造實物，失敗的掛售不留下免費庫存。吹牛、承諾和玩笑商品不會直接增加金錢或物品。

錯誤 API、空回覆、無效 JSON 或未知身份不回退模板。重複點擊和其他標籤頁正在生成時拒絕開啟另一輪；生成鎖和市場寫鎖分開，用戶仍可在其他頁面交易。離開整個市場浮層會取消請求，關閉 NPC 或已取消的一輪在寫入前再次檢查，不再補寫。關閉 NPC 時，隨機刷新只會嘗試已開啟自由活動的自家角色；沒有合適角色則提示，沒有路人模型調用。

不帶事件的零酬謝 favor 繼續使用原便箋格式（不遷移舊檔），列表顯示「便箋 / 留句話」，詳情不展示酬謝 0。回覆仍不結算；提交完成文字約定會封存該便箋。

- `utils/vrWorld/marketNPCs.ts`：現場快照、群像提示詞、JSON 校驗、順序動作執行。
- `utils/vrWorld/marketNPCSession.ts`：API 選擇、整輪調用、跨頁互斥、取消與新鮮狀態保存。
- `FishingMarketOverlay.tsx`：沿用刷新與指定角色入口，顯示來訪中、失敗及部分動作未執行的狀態。
- `utils/marketRefresh.test.ts`：整輪多位路人、新帖引用、有限錢包、非法身份和資源、API 失敗、取消與併發。
- `utils/vrWorld/marketEncounters.test.ts` / `fishingSession.test.ts`：隱藏事件、付費/酬謝/免費、一次結算、角色反應與卡片、失敗不展示、備份與臨時身份。
- `scripts/test-sar-market-encounters.mjs`：隔離瀏覽器驗證公開帖不劇透、參與無額外模型調用、連續點擊、往期回看與 320px 界面。
- `scripts/test-sar-board-refresh.mjs`：隔離瀏覽器模擬 API，驗證多角色帖子/回覆實際渲染、一輪一次請求、指定角色原流程、錯誤時不補帖子與小屏。模擬台詞僅在測試裡，正式代碼不包含示例句庫。
