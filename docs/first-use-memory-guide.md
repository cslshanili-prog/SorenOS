# 首次使用：API 與記憶引導

在角色庫成功讀取、尚未插入內置 Sully 時判斷是否首次使用。只有空角色庫且沒有引導標記時自動開始；已有用戶標記完成，不彈新手流程。讀取 DB 失敗時不做新用戶判斷。

`os_first_use_memory_guide_v1` 保存 0–6 的步驟或 `done`，刷新後從原步驟續接。引導掛在 `PhoneShell` 的 App 容器外，跨 App 保留，可摺疊且不遮擋表單。免責聲明、導入恢復提示仍優先；週年贈禮和版本公告等待引導完成。

1. 自動打開設置、展開 API 配置，保存完整 URL / Key / 模型後可繼續。
2. 引導期間只顯示副 API 與 Embedding API 兩個配置區，隱藏全局頁面的其它選項。全自動記憶需要兩者均完整配置；副 API 可點擊「我想暫時只用主 API」，複製主 API 配置用於文字整理，不調用模型。Embedding 區提供「暫時跳過向量記憶」：完成副 API 選擇即可跳過，直接進入聊天教學，不開啟記憶開關。跳過狀態通過 `os_first_use_skip_vector_v1` 持久化，流程顯示為六步，結尾明確提醒稍後補配；返回第二步並完成兩項配置後可恢復七步完整流程。提供硅基流動網頁版實名認證提示，也允許熟悉 Embedding 的用戶自行配置兼容服務。
3. 回到記憶宮殿角色列表，圈出 Sully 的記憶開關，等待用戶主動開啟記憶宮殿與全自動記憶。
4. 打開神經鏈接，由用戶點 Sully、發消息進入聊天。
5. 圈出實際聊天生成按鈕，僅介紹位置及費用，不點擊生成，不發送測試消息。
6. 返回桌面，必須觀察到桌面已渲染，再等待用戶點擊聊天 App。
7. 解釋自動整理、原始文字檔案與向量記憶的區別、神經鏈接的編輯入口，以及聊天加號設置中手動向量化並非常規操作。

配置門禁只判斷已保存的必填字段，不聲稱服務連通，不自動發起 API 測試。所有記憶開關沿用原有處理函數，引導不額外改寫角色記憶策略。

每一步都有「直接跳過引導」，收起後仍顯示。點擊即持久化完成狀態，停留當前頁面、不改已有配置、不自動開啟記憶或調用 API。入口使用加粗光圈、柔和呼吸效果和帶箭頭的文字提示；提示不攔截點擊，隨滾動/縮放重新定位，系統要求減少動畫時關閉呼吸效果。神經鏈接依次指向 Sully 卡片、發消息按鈕；記憶開關依次指向尚未開啟的開關。生成按鈕只標識位置，不引導點擊。

實名認證要求依據硅基流動[官方公告](https://docs.siliconflow.cn/docs/release-notes/overview)；權益、價格以服務商為準。

實現：`components/FirstUseGuide.tsx`、`utils/firstUseGuide.ts`。迴歸測試：`utils/firstUseGuide.test.ts`，覆蓋老用戶不彈、刷新續接、配置/開關門禁、桌面跳轉時序和不點擊生成。
