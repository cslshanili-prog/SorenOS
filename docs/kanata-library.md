# 彼方書庫與分類閱讀

書庫支持按書名、作者搜索，按分類篩選，每頁顯示 12 本。常用操作只有「上架」「分類」「整理」：分類中創建、重命名或移除分類；整理中勾選書籍、選擇本頁，並批量移入分類。每本書歸屬一個分類；舊書默認未分類。移除分類只把書放回未分類，不刪除正文、書籤或批註。書籍下架仍會刪除對應批註，需單獨確認。

在某個分類下點上架，會默認選中該分類；上架彈窗也可以改選。TXT、PDF 與粘貼正文沿用原導入流程。

## 角色閱讀偏好

入口為書庫底部「誰來讀這些書」，或「接入」裡的角色閱讀偏好。三種方式：

- **全部輪換**：在全書庫尚未讀完的書中輪換；都讀完後重讀。
- **按分類**：可選擇多個分類，只在這些分類的並集中輪換。新歸入的書自動加入，不需要再次修改角色偏好。讀完後在這些分類內重讀；分類為空、未選分類或所選分類已被移除時，暫停圖書館閱讀，不回退其他書。其他彼方活動照常運行。
- **逐本優先**：保留舊規則，先在圈定的書中讀，讀完後回到全書庫；沒有指定書時等同全部輪換。

每種方式保留自己的選擇，切換方式不會擦掉另外一種選擇。有多個候選時排除上次讀的書，避免連續兩輪重複。每本書的角色書籤和批註保持獨立。

## 存儲與實現

- `VRWorldNovel.categoryId` 保存分類的穩定 ID。
- 分類 `{ id, name }` 存在現有 IndexedDB `vr_settings` 的 `library-categories-v1` 記錄中，不新建數據庫或 localStorage 副本。空分類也能保存，重命名不改變 ID。
- `VRWorldCharState.novelReadingMode` 為 `all / categories / books`；分類選擇為 `preferredNovelCategoryIds`，逐本選擇仍為 `preferredNovelIds`。舊檔缺模式時，有逐本選擇則沿用 books，否則 all。
- `DB.editVRLibrary` 在同一讀寫事務中讀最新分類與書籍、校驗操作、保存分類和書籍歸屬；失敗整體回滾，不寫入部分移動結果。正文、創建時間、批註與角色記錄不被整理操作覆蓋。
- 全量備份已有的 `vrNovels`、`vrSettings` 和角色記錄覆蓋這三部分；恢復沿用原字段透傳。刪除分類不自動清掉角色的分類 ID，避免意外變成全書庫；偏好頁顯示失效選擇，用戶可清除或重新選擇。
- `utils/vrWorld/library.ts` 集中分類校驗及閱讀範圍；`runSession.ts` 的手動和自動閱讀都使用同一規則。沒有候選時，自動活動池不放入圖書館；手動指定圖書館也不偷偷換房間。
- 活動生成期間更新偏好，以保存時的最新角色偏好為準，避免舊會話結果覆蓋新範圍；已經開始的一次閱讀可能仍完成原書本輪批註。
- UI 位於 `apps/vrWorld/VRLibrary.tsx` 和 `vr-library.css`。偏好彈窗共用 iOS 頂部、底部安全區，正文獨立滾動。

## 驗證

`utils/vrWorld/library.test.ts` 覆蓋分類範圍、舊檔兼容、空範圍、讀完後的輪換、重命名、批量移動、刪除和併發偏好保留。`scripts/test-vr-library.mjs` 使用隔離瀏覽器檢查實際批量歸類、新書導入自動加入、書籤/批註保留、刷新後持久化、備份字段和橫豎屏安全區。
