# 恐龍箱庭

當前實現核對：2026-09-11。

移動端優先的橡皮泥模型箱庭。入口在 SAR 活動室茶几上，也能從釣魚收藏進入。沒有咖啡店或戰鬥系統。面向用戶的全設施流程和模型調用說明見 [SAR 活動室怎麼玩](../../docs/sar-user-guide.md)。

## 庭院操作與物品互動

打開先看整座庭院，不自動選中恐龍。底部只有「佈置／恐龍／來訪」三個入口；首次有可收起的小引導。點恐龍打開輕量小面板，再換地方、換顏色或寫一句。圖鑑放在「恐龍」，全部事件放在「來訪足跡」。

「正在」只是一句話，不要求行為標籤或對象。留空時顯示所在位置的小日常。自定義句子仍保留署名與歷史，移動地圖、換色和環境動畫不會覆蓋它；已有存檔的行為和對象繼續兼容。角色也可以只提供 stage + words 來續寫，無需提供標籤。

`dinosaurActivities.ts` 從保存的格位、朝向和附近擺件分配互動。玩具用品與純裝飾分開：野餐墊上啃餅乾並掉碎屑、水窪/淺水交替抬腳濺水、花叢低頭聞花且花朵輕晃、面對小樹夠葉子、帳篷門口或石旁蜷起來呼吸、木樁中央搖尾巴放哨。火山、柵欄、路牌和玩具小屋只作為裝飾。蛋和骨架保持靜態。每個互動物品同時分配給一隻恐龍；不滿足距離、朝向或佔位條件就不觸發。

互動擺件在場景中有小爪印入口與淺色光圈，可直接點開詳情，再選「讓恐龍來玩」。接著從收藏中選一隻，程序預覽可互動的空格，仍須用戶確認。 來玩列表在點擊前說明可用、滿員、佔用或靜態藏品。詳情入口與場景入口共用 `planGardenPlay`，會搜索全部八個朝向；舊自由擺件沒有可用格子時，可預覽恐龍與這件未被佔用的擺件一起調整，確認後在一次存檔事務裡保存兩者，取消均不改變。不移動其他恐龍、不重置其他擺件。佈置菜單提供對應擺件的小圖和用途說明，不再通過文字列表選擇目的地。

**所有添加、移動、轉向都經過預覽 → 調整位置/朝向 → 確定。** `dinosaurPlacement.ts` 的草稿只保留在當前組件，渲染副本不寫入存檔、計數或事件。格子標出可放和佔用，選中物品發亮並顯示朝向箭頭；無效預覽變紅並禁用確認。取消或離開直接丟棄草稿；點確定後才在寫鎖內複核地圖、修訂號、所有權、容量和佔位，並生成一次事件。其他頁面/來訪改變庭院時，舊草稿必須重新選擇。新擺件只在確認後分配真實 ID。收起擺件有面板內二次確認。

**恐龍的位置和朝向始終固定在用戶確認的數值。** 不再往返移動到擺件，也不自動轉身。原地動作採用頭、尾、腳三個輕量 morph 通道，保持身體、眼睛和顏色一起變形；擺件與餅乾碎屑/水花給出相應反饋。木樁提供靜態支撐高度。不會逐幀寫存檔或調用 LLM。固定開關仍表示禁止角色改動；「正在」的一句話不決定任意動畫，角色提示詞共用實際支持的環境互動。每圖最多六隻恐龍和十二件擺件。

## 地圖與美術

- 溪邊草原：草坡、溪流、木橋、花叢、蘑菇、彩旗、營地。
- 貝殼海岸：弧形沙灘、淺水灣、棕櫚樹、燈塔、遮陽傘、貝殼、海星、玩具帆船。沒有橋或草原的柵欄和彩旗。
- 火山探險：灰褐色巖台、橡皮泥熔岩、晶簇、化石壓印、探險補給、圓火山和煙團。沒有溪流、橋或彩旗。

三張地圖分別構圖，共用底座與低成本幾何生成器。每張地圖獨立保存擺件和恐龍位置，所有角色共用每圖六個恐龍名額。當前開放三張地圖；尚未接活動解鎖更多主題。用戶和現有角色的收藏可一起擺放，歸屬不因擺放而改變。

恐龍以用戶參考圖為依據離線生成 GLB：連續的圓潤身體、啞光頂點色、保留眼睛和表情。原有十二種收藏及新增劇情專屬混合恐龍均有模型，共十三種模型資產。UV 兩通道作為身體和細節的換色權重，不需要貼圖。六組配色及兩個色盤只作用於當前單隻；預覽可取消。自由手繪尚未實現。

艾文三星事件的「？？？」使用穩定 `speciesId: aiven-chimera`：霸王龍身體、三角龍角、劍龍背板、腕龍長脖子與異常拼色。沿用橡皮泥 SDF 建模、圖標、換色和原地動作系統；單網格 8,236 三角面、約 301 KiB，劇情近看與箱庭按需加載同一 GLB。它是明確贈送一次的真實收藏，名冊回看只有演出，不重新發放；不進入垂釣、普通隨機贈禮或蛋的孵化池。

恐龍蛋從隨機垂釣池移除，新檔由艾文三星話題贈送並開放對應圖鑑。舊檔已持有或歷史獲得的蛋繼續可見與使用；孵化六小時後手動揭曉標準活體恐龍，蛋和骨架本身保持靜態。十三種模型資產不等於十三種當前可釣藏品，也不等於所有用戶圖鑑始終顯示相同總數。

## 隱藏棋盤

`dinosaurGrid.ts` 固定 A～F 六行、每行五格。恐龍位置吸附到這三十個落點，朝向量化為八個方向。平常不顯示棋盤；擺放時顯示方格輪廓與有效/佔用顏色。每隻只佔一格，每圖最多六隻，擺件會封鎖附近落點。燈塔、遮陽傘等固定佈景也使用共用地標位置校驗佔位，手動擺放、角色動作和舊自由座標遷移都會避讓。用戶可跨地圖移動同一只恐龍，不產生副本。

角色模型可以輸出具體 `slotId`，或 `anchorId + near/face`。代碼負責查找空格、佔位、擺件避讓和朝向；任意自由座標不進入執行器。新手動擺件同樣吸附棋盤，已有的自由擺件座標不會在打開存檔時被強制改寫；調整時仍檢查邊界和碰撞。

## 身份、記錄與存檔

所有內容在既有 `vr_fishing_market_v1` 的 `dinosaurGarden` 中，完整進入原 SAR 本地備份。沒有新的遠端數據庫。首次打開只贈送一隻真實收藏項；帳本標記避免反覆領取，來源明確記錄為艾文的贈禮。

個人線進度與獎勵收據存於同一市場記錄的 `sarFamiliarity`，其恐龍贈禮進入共用庫存，不另建展示用背包。首次箱庭贈禮與劇情贈禮分別去重。完整 ZIP 保留相關個人線紀念照片；純文字備份保留箱庭、收藏、個人線文字與進度，去掉圖片內容。

單隻身份綁定 `FishingCatch.id`，保留名字、配色、獲得者/來源、原始用戶狀態、當前狀態、地圖/格位、固定狀態和修訂號。同種多只完全獨立；贈送保留身份和經歷，並向受贈角色寫入事實回執。掛板或孵化中的藏品不能擺放；圖鑑發現記錄和當前持有數量分開。

用戶可直接留一句小劇場；舊版十二種行為和對象字段保持兼容。來訪只追加當前狀態和署名，不修改用戶原文。事件歷史不裁剪；可回覆便籤、定位恐龍、回看舊位置。還原僅在目標之後沒有變化、舊位置仍空閒時允許，且追加還原事件，不抹去來訪記錄。

早期單桌預覽會遷移為多地圖，舊自由位置吸附到不衝突的格位，個體信息保留。損壞/未知結構不會被初始化覆蓋，原始內容仍能通過既有備份導出。Web Locks 串行化本頁和其他標籤頁的寫入；驗證拋錯後也必須釋放鎖。

## 角色來訪的實際邊界

真實入口使用 `runVRSession` 原有角色人格、上下文和 API 優先級。一次會話選擇評論、移動或續寫中的一個動作；固定恐龍只接受評論。執行時重新讀取存檔，核對地圖、修訂號、所有權、格位和共同擺弄開關。切換正在查看的地圖不會把角色動作挪到另一張圖。

自動來訪掛在原有彼方在線活動調度中，每角色至少間隔十二小時，全局二十四小時最多三次；用戶手動邀請不受自動頻率限制。**關閉應用期間不會新產生來訪**，沒有實現後台 Worker 來訪，也不補刷離線天數。試玩頁使用明確標註的“示例來客”固定回覆，不調用模型；生產入口才調用用戶配置的模型。

## 性能與驗證

只加載、顯示當前地圖所需模型；圖鑑近看只顯示單隻。地形只在切換主題時重建，可編輯擺件按身份保留網格，移動和轉向只更新變換。每種恐龍的動作通道在模板加載時計算一次，實例克隆獨立幾何與配色；互動粒子每隻合為一個 InstancedMesh。場景爪印與地面光圈保留獨立透明繪製，避免遮蓋地形。

DPR 上限 1.4，繪圖緩衝區同時限制在一百萬像素內。只有原地互動、打招呼和視角阻尼需要持續畫幀，上限 30 fps；靜止近看、擺放預覽和減少動態效果按需重畫，圖鑑完全遮住畫面時暫停渲染與隱藏居民同步。512 陰影在佈置變更時更新，動畫期間最多每秒更新三次。離屏／後台停畫，關閉顯式釋放幾何、材質、紋理、實例緩存和 WebGL 上下文。無後處理或水面折射。

同一 390×844、DPR 2 瀏覽器場景（四隻恐龍）採樣：普通幀／陰影更新幀的繪製調用由 59／74 降到 44／59；靜止近看、擺放和隱藏圖鑑的採樣區間均為零新增繪製幀。旋轉擺件不增加地形或擺件幾何生成次數，多次圖鑑進出後 GPU 資源計數穩定。`qa-performance.mjs` 驗證這些邊界和寬屏像素預算，`qa-integration.mjs` 還檢查退出入口後 WebGL 上下文釋放。真機幀率尚未測量，不能把桌面模擬手機的結果當作真機性能保證。
