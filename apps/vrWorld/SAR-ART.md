# SAR 活動室美術對接

當前實現核對：2026-09-11。個人線流程與獎勵見 [SAR 個人線](../../docs/sar-personal-lines.md)。

## 素材與空間

- `assets/sar-club-room.png` 是用戶提供的 1348 × 2439 活動室原圖。
- `assets/sar/room-walk-mask.png` 與底圖同畫布，綠色為釣魚站位，橙紅色為其他活動站位。白色不可站立。
- `assets/sar/room-hotspots.png` 提取五個設施中心；恐龍入口額外放在茶几 `(790, 1300)`。佈告板、模塊櫃檯、芯片陳列、扭蛋機、釣魚與恐龍均連接原功能入口。
- `prototypes/sar-art/read-room-mask.py` 使用 Pillow 分析原始像素，生成 `utils/vrWorld/sarRoomMask.json` 的逐行色區和候選腳底位置；不修改源圖。
- `sarRoomLayout.ts` 按角色 ID 穩定分配候選位置，檢查色區、腳底範圍、角色間距與設施按鈕避讓。滿員進入候位名單，不把多人塞進同一個位置。佈局不讓角色穿過傢俱漫遊。

凱恩、艾文的 chibi 分別對應用戶原始 `6_0_1 (6).png`、`6_0_1 (12).png`。保留完整 472 × 472 透明畫布，不裁 NPC 邊距。NPC 和訪客共享基礎尺寸及腳底基線（原圖腳底 y = 427，即底部透明邊距 45 / 472）；訪客原有自定義縮放、翻轉仍保留。

房間層級從低到高為底圖、設施文字標記（10）、角色 chibi（按腳底深度 20–50）。文字與小人重疊時，小人在上層；未被遮擋的設施標記仍可點擊。

## 對話立繪

`SARDialogueBackdrop` 與活動室共享整屏取景範圍和原圖等比縮放；打開初見、日常或回放時，背景的位置與尺寸不隨立繪舞台和對話框改變。共用取景規則在 `sar-club-room.css`，不要在 `.srf-stage` 重新裁切背景。

`utils/vrWorld/sarArt.ts` 註冊用戶原畫的 17 種表情：凱恩 11 種 `normal / happy / curious / embarrassed / serious / shy / aboutaster / Enduring Pain / avoidant / normal2 / warm`，艾文 6 種 `normal / happy / interested / sad / shy / sleeping`。新增四種在校對界面顯示為「忍痛 / 迴避 / 平常2 / 溫柔」，`Enduring Pain` 的大小寫與空格按原名保留。正式素材在 `public/sar-portraits/Caian` 和 `public/sar-portraits/Aiven`，保留原畫布比例，最大邊 1500 px 的 WebP 合計 3,190,522 B（約 3.19 MB）。新增四張已同步素材提交 `01edb974` 的 2629 × 2899 透明 PNG，並保留透明通道重新生成 WebP；加載地址附帶素材版本，避免複用舊白底緩存。原有 13 張素材及其透明信息保持不變；新增素材可用於手動校對，已應用用戶校對的表情編排，校對草稿與導出支持新增值。

`SARNpcArt.tsx` 優先按需加載本地 WebP，失敗才經原 `CdnImg` 鏡像鏈請求相應 PNG；仍失敗則回退 normal，再失敗顯示重試。房間不預載全部立繪；切換表情時保留上一張已加載圖片，成功 URL 在會話中複用。

`SARDialogueCast` 以當前個人線的 `lead` 為主角，另一位實際發言才進入雙人同框，凱恩左、艾文右。聽者降低亮度但保持不透明。對方出現後留到當前節點結束，跨節點檢查後續六句，有台詞則繼續留場；只提名字或設置聽者表情不觸發首次出場。初遇與個人線、名冊回放使用同一套規則。

個人線演出由 `SARFamiliarityDialog.tsx` 與 `sar-familiarity-dialog.css` 承載。正文逐句使用指定表情，旁白保持最近情緒；證件、合照等特殊演出佔據主畫面時，台詞邊保留當前角色的情緒頭像。關閉 NPC 的設置同時隱藏兩人的房間與對話入口，設施仍可用。

初遇腳本逐句指定表情，覆蓋凱恩原有七種立繪。拆台台詞當句保持凱恩此前的表情，他接下一句時才變為 embarrassed。`getSARDialogueNode` 先過濾條件台詞，再逐句生成表情快照；換分支重新計算。個人線表情保留到當前閱讀結束，中斷後整段重開。

## 名冊與特殊演出

「倉庫 → 圖鑑」用「收藏 / 名冊」切換。名冊採用暖白檔案佈局、normal 表情立繪與完整原文簡介，顯示五顆星，只開放寫好的前三星；已完成的話題、星級事件與彩蛋可回看，鎖定項不洩露標題和內容。名冊屬於用戶，不隨倉庫當前主人變化。

成員證使用用戶當時的 chibi；會議記錄顯示實際分支結論；合照支持拖動/縮放人物、背景取景、修改自己形象和加入自家角色。合照與證件保存當時姓名、日期、圖片引用和構圖，倉庫「紀念」可查看，後續換形象不改舊照片。回放只讀，不重領紀念物。

禮炮、三張優惠券雨、物品堆和神秘按鈕由原生 UI 動效實現，非交互特效可直接按普通對話繼續。混合恐龍「？？？」複用正式橡皮泥 GLB 渲染器，規則與性能見 [恐龍箱庭](./DINOSAUR-GARDEN.md)。特效道具與真實贈品分別按劇情節點定義，不能根據畫面出現什麼就發什麼。

## 臨時立繪調節器

在 Vite 開發服務器打開 `/prototypes/sar-art/index.html?edit=portraits`（端口以啟動輸出為準）。

僅存在於原型入口，不進入 VRWorldApp。分別調整大小、左右、上下，以及前後遮擋順序；實時使用正式對話組件預覽，允許重疊。正 y 向上，x / y 均相對立繪場景尺寸；scale 的 150 對應已定稿的標準大小。參數保存在當前瀏覽器的 `sar-art:portrait-layout-draft:v1`，可複製、查看、恢復上一版。手機可收起控制面板。

雙人同框的位置參數：兩人 scale = 150，凱恩 x = 27，艾文 x = 75，y 均為 0，front = auto；單人模式只改變水平居中位置，保持與雙人同框完全一致的立繪高度和原圖比例；不再按舞台寬度縮小。問候與劇情共用這套尺寸。兩人統一縮小到此前尺寸的 85%，單人與雙人使用同一比例；撤掉額外下移，下緣錨定對話框上沿，避免縮小後身體懸空。這些參數寫入正式 CSS，臨時編輯器的草稿不會自動覆蓋正式參數。

初遇和日常共用淺色全屏佈局：無頂部信息欄、可伸展的立繪舞台、底部固定高度氣泡；人物名、星級、回顧標題和返回按鈕統一位於氣泡的名字行；取消初遇上下黑邊。選擇浮層居中，不擠佔氣泡和立繪的佈局。選項使用當前界面同一底色，懸停與焦點只用輪廓提示，不變紫或變成另一種主題。橫屏仍按可用高度排列；特殊演出保留獨立主畫面。
