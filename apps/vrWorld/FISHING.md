# 水域與佈告板

當前實現核對：2026-09-11。個人線贈禮與解鎖規則見 [SAR 個人線](../../docs/sar-personal-lines.md)，錢包、抽取和優惠見 [數值規劃](../../docs/sar-economy.md)。

入口：彼方頂部 SAR 入口內 的「水域」與「佈告板」是兩個並列設施。水域包含釣魚/圖鑑和角色釣魚；佈告板首頁為合併便箋流與統一發布入口，發佈和詳情使用獨立頁面，行情/往期便箋/角色邀請收在「更多」子頁面。收支記錄、匿名署名和規則說明默認摺疊，付款與收款方向顯示在成交按鈕上。兩者共用本地錢包、收藏與市場存檔，離開後都返回 SAR；收藏中定價掛板成功會轉入佈告板。市場完全在這一家用戶的本地世界運行；不創建跨用戶帖子、不調用 Cloudflare 行情、不增加 D1 表。

## 玩法與數據

- 9 種魚使用 `FishArt.tsx` + `fishing.css` 的 CSS 輪廓、鰭、鱗片與動畫，無生圖或圖片依賴。原有 12 種恐龍/蛋/骨架定義保留舊 `speciesId` / `time-relic` 存檔兼容，另有劇情專屬混合恐龍 `aiven-chimera`。收藏使用輕量輪廓，進入箱庭按需加載 3D 模型。詳見 [恐龍箱庭](./DINOSAUR-GARDEN.md)。
- 隨機垂釣池是 9 種魚及 11 種普通橡皮泥藏品：恐龍蛋已移出隨機池；`STORY_CATCH_CATALOG` 中的專屬混合恐龍也不參與抽取。蛋由艾文三星話題贈送並開放圖鑑，舊檔持有或歷史獲得的蛋繼續可見。圖鑑目錄與隨機垂釣池不是同一集合，不按固定總數判斷解鎖。
- 手動釣魚採用圓弧追蹤：按住水面/Space 順時針，鬆開逆時針，可收竿、F 全屏。簡單模式先看水面魚影，點附近拋竿（底部按鈕可自動瞄準），經過落水、等待與收線動畫後判定釣獲或空軍，不進入光弧追蹤小遊戲；模式偏好保存在本機。兩種模式共用魚種/大小/品質抽取和入庫事務，逃脫或空軍不入庫，保存中阻止重複拋竿，存儲失敗可重試同一釣獲。
- 水面佔主要畫面，只保留天氣來源、手動/簡單切換和拋竿操作。釣獲在水面上展示，說明收進問號，角色釣魚從底部摺疊入口展開；模型調用提示仍在角色邀請操作前顯示。交互區阻止長按菜單、文字選擇與圖片拖拽，不影響收藏頁。
- 開啟真實感知天氣時複用 `RealtimeContextManager.fetchWeather`；未開/失敗則使用本世界當日模擬天氣，並明確顯示來源。天氣改變出沒權重，不強制絕版魚種。
- 魚獲詳情的「賣給艾文」為用戶入口，角色可在本次釣魚結束時自行選擇售魚。艾文從五句固定回話中選一句配表情，無額外模型調用；成交回執在水域和角色活動卡中顯示，並隨原市場存檔導出。恐龍不由艾文按魚價收購。
- 用戶和每個角色各有獨立初始 120 鱗幣（舊餘額保留）；隨機路人另有有限錢包。系統回收每人每天最多發放 180 鱗幣，超額時不收走物品；錢包新增收入上限 999,999，舊的超額餘額保留且可繼續花費。每日行情由世界 seed + 本地日曆日確定，包含真實前一日對比，斷登不改變價格邏輯。
- 首頁只有合併便箋流和「寫便箋」入口，購買、求購、文字回應與收取心意放進發布/詳情頁面；當日行情在「更多」。支持 0 元掛單、沒有實體的文字商品、實物求購、文字招募、向發帖人付款的打賞。評論不觸發付款，實物交付必須持有且未掛單/孵化。
- 24 小時/成交/主動撤下即封存；原文、評論、交易方和交付內容完整留在發帖方檔案。餘額、收藏及檔案不按數量截斷；存儲額度耗盡會報錯。
- 恐龍可陳列/製作一次觀察記錄/交易；恐龍蛋孵化 6 小時後手動揭曉，期間鎖定交易與放生。孵化和普通隨機贈禮只從標準活體恐龍中選，不產生蛋、骨架或專屬混合恐龍。
- 個人線明確贈送的恐龍作為真實 `FishingCatch` 入用戶收藏，保留來源、身份與收集記錄；特效中的其他物品不自動入庫。劇情節點收據阻止重複領取，名冊回放不發獎。
- `vr_fishing_market_v1` 保存市場、錢包、收藏、圖鑑、回執和 `sarFamiliarity`。`sarBackup.ts` 接入完整備份，連損壞的原始串也能導出搶救，不因讀取失敗覆蓋原存檔。完整 ZIP 同時保留個人線照片的本地圖片，純文字備份保留文字與進度、剝離圖片。

## 角色與事實邊界

`runVRSession` 的水域/市場分支各使用一次正常 LLM 調用。角色釣魚在同一輪給出保留／放生／賣給艾文、反應與可選私聊分享。售魚用 `disposition: "sell"`，可額外給出 `saleWords` 作為交魚時的原話；模型不能自定價格或編寫艾文的回覆。程序按結算當天行情和品質發放鱗幣，沿用每日回收額度與錢包上限，保存一次隨機台詞和表情。失敗時魚獲保持待處理，不發成交分享；重試不重抽魚、不重複支付。首次圖鑑播報由程序完成；其他掛單與交易仍在佈告板。市場分支選擇購買、響應、回覆、發帖、撤板或路過。市場私聊分享目前仍保存在活動卡，未單獨發送普通聊天消息。

實物求購支持用戶選擇具體藏品，角色用 `CATCH` 指定交付對象。省略時僅兼容唯一可用藏品；有多件就拒絕代選。提交時重查庫存，所選對象失效不會拿同種其他件替代。新掛單及求購交付保存 `MarketCatchSnapshot`，包含大小、星級、恐龍名字，不含主人身份；模型可區分實物與文字商品，檔案在後續轉手／放生後仍能展示當時資料。匿名便箋的作者回復默認沿用該便箋筆名。

金額/物品轉移由純函數驗證，模型說“已付款”不能觸發支付。代碼事務讀最新狀態，並用 Web Locks 串行化跨標籤頁修改；模型調用不持鎖。每個實際交易/評論為相關角色寫入去重的 `vr_card` 回執，即使對方不是當前活動角色，也會獲得事實與當時原話。後續活動讀取這些卡片；原有聊天/記憶流程繼續接收它們。回執把程序事實與主觀隨筆/誇張台詞分欄，不能把喊話當作真實債務、人格變化或指令。

普通房間不新增水域提示詞，不初始化水域存檔。模塊商店、Chat、Date 的原有 SAR canonical / surface 邊界不變。

`worker/post-office/src/index.ts` 已移除舊寫詩執行體；所有公開詩歌寫入及新冊/恢復接口在訪問 D1 前返回 410。紀念館 GET 只執行 SELECT，不執行自動建冊、播種或舊冊規格遷移。2026-09-06 的歷史交接記錄僅確認本地代碼和部署包，當時未部署線上 Worker、未刪除遠端數據；本次個人線更新不變更該服務，不據此推斷線上部署狀態。
