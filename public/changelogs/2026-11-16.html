01裝扮 App：取代氣泡工坊

桌面 → 裝扮；聊天「＋」、群聊「＋」→ 裝扮
  • 佈局、氣泡、背景、聲音、白框 CSS 做成一套一套的模板，套用就是把模板寫進角色、全局或群原本的欄位；改模板，所有用它的聊天一起變。
  • 模板能原地複製一份來改、改名；新模板先取名。預覽用的是真的聊天元件，看到什麼就是什麼。
  • 聊天和群聊「＋」裡的入口只做兩件事：選模板、連去 App。群只套群吃得到的那幾樣。
  • 綁著模板的聊天也能單獨換氣泡，模板照舊。
  • Sore 收得了 .css／.txt／.json，能讀你的裝扮、出「改裝扮」的提案：改模板寫穿、某個聊天換模板、跟著全局、或直接改成自訂；一樣先給你看，套用才寫，可還原。
  • 聊天設定、群組設置、聊天裡的彈窗和全螢幕頁搬到 body 上，白框 CSS 不再把開關和按鈕一起染色；系統提示長的不再是大橢圓。

02聊天語言

聊天設定 → 聊天語言
  • 每個角色設說話語言、夾雜第二語言（多少比例）、翻譯成哪種語言。設定存在角色卡上，私聊、電話、群聊、見面都讀同一份。
  • 翻譯有兩條路：讓模型順便寫（雙語），或接 DeepL（在設定 → 翻譯 API 填 Key），角色先寫原文再翻。你自己發的訊息也能自動譯出成角色的語言。
  • 雲端（即時對話、主動消息）照說話語言寫，收件後在本機補譯文，所以雲端那頭不用改。
  • 電話的說話辨識改成繁體，跟語音條同一個辨識語言設定。

03你的聲音

身份卡 → 聲音；私聊輸入欄 → 語音條模式
  • 身份卡可以設音色（跟角色頁同一組欄位）。設了，私聊裡你能發語音條：打字或說話辨識，送出去是一條可以播的語音；沒設就沒有，不會借角色的聲音。
  • 語音條的內容是純文字，歷史和記憶裡寫成「[語音] 內容」，角色讀得懂。
  • 語音條的零件補齊了 class 鉤子（沒聲音、合成中、角色那條、你那條、麥克風正在聽），做美化的抓得到。

04群聊節奏：你一句我一句

群組設置 → 一輪幾個氣泡；群聊畫面右側 ▸
  • 一次出場只寫一兩個氣泡，不再一個人一口氣講完一段；一輪總共幾個氣泡在群設定裡調。
  • 各自發言模式先排出場表再依序叫，誰先誰後有章法（排班用副 API，失敗就退回每人一拍）。
  • 旁觀欄多一顆 ▸ 按鈕：你不說話，讓他們自己接著聊。
  • 成員各自認識不同身份卡時，提示詞會說清楚「他／她」指的是誰；配角客串修好了；群聊總結幾條一組可以調；私聊看得到所有還沒成盒的群聊。

05切換聊天與世界分組

私聊頂端點名字；神經鏈接 → 世界與分組
  • 切換聊天改成全螢幕頁：最近聊過一排、搜尋（名字、暱稱、世界、分組）、主角／配角／有未讀篩選，底下照世界收起來。
  • 世界底下可以再分組（一人一組），切換聊天和選角色的地方都照分組排；「世界與分組」管理也改全螢幕。
  • 神經鏈接：主線可以換成另一張身份卡；關係編輯搬回角色編輯頁。
