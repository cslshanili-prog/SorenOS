01描述拆成三格

神經鏈接 → 角色頁，名字下面
  • 別名：TA 本來就有的其他名字，本名、英文名、綽號、圈名，用逗號或頓號分開，最多 8 個。你自己對 TA 的叫法不是填這裡，那個在聊天設定的「暱稱」，沒有動。
  • 身份／職位：攝影師、段家長子、大三學生這種。
  • 簡介：一句話介紹。就是以前那格「描述」，原本寫的字都還在，不用重填。
  • AI 幫我填：讀下面的人設，空的格子直接填上；已經有字的不蓋，把建議列在那格底下，要換自己按「換成這個」。
  • 各種清單上名字下面的小字改成「身份 · 簡介」；搜尋角色時，打別名或身份也找得到。
  • 給 AI 看的角色介紹跟著帶上身份和別名：私聊、群聊、劇情、電話、查手機、朋友圈都是。沒填新格子的角色，送出去的字跟以前一樣。

02寫別名也認得出是誰

群聊、私下找人、行事曆、查手機、家園、匯入聊天、Sore
  • 以前系統只認卡上的名字，角色寫了別名就當作沒這個人。現在這些地方都認別名：角色私下傳訊息給誰、群聊紅包發給誰、群聊誰接話、日程裡跟誰有約、查手機聯繫人對回真角色、家園的私信、匯入聊天時預選角色、請 Sore 改某個角色的東西。
  • 規則：名字優先，名字對不上才看別名，而且別名要剛好只有一個人有。兩個人別名一樣，就當沒認出來，不亂猜。
  • 同一個世界裡別名撞到別人時，別名那格底下會提醒（撞到名字、撞到別名兩種），照樣可以存。
  • 私聊的「你身邊的人」名單也帶別名：你跟角色提到「Vivian」，TA 知道那是自己關係清單上的誰。
  • 小號的別名是小號自己的，不會從本人那邊帶過來，不會因為別名被認出來。

03一次補一批

神經鏈接 → 主角／配角那排右邊「補別名與身份」
  • 勾角色 → 一起讀人設（同時讀 3 個）→ 逐個看結果 → 最後一次存。按存之前不會寫進角色。
  • 預設勾的是別名和身份都還空著、又有人設可讀的；切到「全部」可以重讀已經填過的。
  • 每個角色三格都能再改，可以「不要這個」；讀失敗的會寫原因、可以單獨重試；中途可以停。
  • 有字的格子一樣不蓋，只列建議。小號不在清單裡。

04身份卡也有別名

檔案 → 編輯身份，名字下面
  • 真實身份和每張身份卡各填各的。別名跟著卡走：這張卡沒填就是沒有，不會借別張卡的。
  • 角色看得到你的別名（私聊的用戶資料、劇情裡在場的你）。角色私下找你、群聊發專屬紅包、日程寫跟你有約時，寫你的別名也認得。

05Sore 看得到圖了

Sore；識圖在 系統設置 → API 設定 → 識圖 API
  • 識圖 API 開著：圖先交給識圖模型轉成文字再給 Sore，Sore 用的模型不能看圖也沒關係。圖下面可以點開看轉述寫了什麼。同一張圖只識別一次。
  • 沒開：圖直接交給 Sore 用的那組模型自己看。
  • 識圖沒成功不會卡住：那一輪 Sore 照樣回答，會跟你說哪張沒看到。圖下面寫原因，要再試自己按「重試識圖」，不會每講一句就自動重來一次。等太久（兩分鐘）沒回會寫清楚是逾時。
  • 回覆可以複製：長按能選字；每則回覆有複製鈕，程式碼各自一塊、各有一顆複製鈕。粗體和行內程式碼會正常顯示。
  • 輸入框會跟著長高，字多了可以開全螢幕寫。手機上 Enter 是換行，送出按右邊的鈕。

06順手改的

聊天、群聊、見面
  • 「見面中」「通話中」那條換顏色：見面是琥珀底深字加一顆愛心，通話是綠底加電話。以前的紅膠囊太像報錯。
  • 聊天頁的彈窗不再被白框 CSS 弄歪：訊息選項、編輯訊息、轉帳詳情、轉發記錄、紅包、整理結果這些原本長在聊天頁裡面，你寫給聊天頁的 CSS 會連它們一起改到。現在搬到外面了。
  • 群聊的「白框自定義」和「提示音」從半個螢幕的面板換成全螢幕頁，白框那頁上面有預覽。
  • 切換聊天頁的返回鍵、篩選鈕底下多出來的陰影拿掉了。
  • 角色頁、身份卡幾格看不清的淺色小字調深，寫清楚那格是什麼。

舊資料不用動：以前的「描述」就是現在的「簡介」。別名和身份是新的兩格，想補的話用「AI 幫我填」或「補別名與身份」。

叫哪個名字，都是同一個人。
