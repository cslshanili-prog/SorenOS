副 API 放一起，
掛了自己換。

記憶、情緒／日程、主動消息三組「副 API」以前散在三個地方，各填各的；現在都在系統設置一處填，從你存的預設選。再給每一組排一條備援鏈：主用的掛了就照順序換下一家重發，不用再一個個進去改。

  • 副 API 中心
  • 備援鏈
  • 雲端

01副 API 中心

系統設置 → 副 API 中心
  • 三格：記憶副 API（記憶整理、月度總結、門牌整理、Sore 預設、回覆草稿；就是原本記憶宮殿那組）、情緒／日程 API（情緒評估、意識流、日程生成、已讀不回判定）、主動消息 2.0 的單獨 API。每格從「API 配置」存的預設裡點一下就填好，也能手填、測連線。
  • 角色頁那格改叫「角色自己的情緒／日程 API」，會寫明目前用的是角色的、系統設置的、還是主 API；多一顆「跟系統設置」把角色的清掉。
  • 解析口徑只有一份：角色自己設的 > 系統設置那格 > 主 API。記憶那格沒設就不跑背景活兒，不會拿主 API 去跑。

02備援鏈

副 API 中心 → 每格底下「備援鏈 ▸」（主 API 也有一格）
  • 從「我的預設」勾幾個進來、▲▼ 排順序。每個旁邊標活著／冷卻中幾分／目前頂著用。
  • 什麼算掛：連不上、逾時、429、5xx。Key 錯（401／403）不算掛，不會換，免得填錯 Key 還一路滾到別家去。
  • 掛了就照順序換下一家再發一次，掛掉的冷卻 5 分鐘，期間直接走換到的那家。模型跟著預設走。
  • 換了家會提醒一次（每組每天一次）、系統日誌記一條，API 調用記錄的用途後面標「（備援 主 API：甲 → 乙）」。串流已經開始吐字就不重來。
  • 沒排鏈的那組跟以前一樣。

03雲端

主動消息 2.0 到點、即時對話、後台任務
  • 本機一換家，雲端那行憑據跟著更新，到點用的是活著的那家。
  • 雲端自己到點掛了不會換下一家（要改上游的 Worker），面板和鏈頁各寫了一行。

以前在記憶宮殿、角色頁、主動消息 2.0 各自填的副 API 都還在原位、照舊生效，搬進中心是加一層，不是搬家。

路斷了就換一條，別停在那裡。
