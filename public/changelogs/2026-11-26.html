羈絆之外，這幾天還有幾件事：點角色頭像能看心聲和今天的日程；朋友圈可以單獨指定一組 API；iPhone 上整合備份到最後被系統關掉的問題，從打包到還原整個換了做法。

01角色名片

私聊、群聊 → 點角色頭像
  • 畫面中間跳出一張小卡（不是半窗）。現在：心聲、此刻在做什麼、還沒褪掉的情緒。今天：TA 的日程。
  • 情緒評估寫了新的心聲，卡片開著也會跟著換。
  • 底下能直接去角色設定、聊天設定（群聊是去私聊）、行事曆「TA 的」、記憶宮殿；在那邊按返回，回到原本的聊天。

02朋友圈 API

系統設置 → 副 API 中心 → 第四格「朋友圈 API」
  • 設了之後，朋友圈相關的一律先用這一組：角色和配角發文、一批留言、作者回覆、角色留言、查手機的軌跡生成。
  • 跟其他副 API 相反：設了就蓋過角色自己的對話模型。沒設照舊用角色自己的。
  • 朋友圈互動設定頁會寫出現在用的是哪一組。備援鏈也認得這一格。

03設置頁整理

系統設置
  • 同類的收成一張卡，用分頁切：API 配置（對話／生圖／識圖／翻譯）、備份與恢復（本地文件／雲端）、語音與寫歌、擴展連接（實時感知／MCP）、主動消息與推送。
  • API 調用記錄和錯誤記錄收成「記錄」一張卡，不用展開就看得到。
  • 設置裡的彈窗都放大了，內容不再擠在一小格裡捲。
  • 副 API 中心每格「從我的預設選」平常收成一行，點開才列；選了預設就把網址、Key、模型收起來。備援鏈的標籤改成看得懂的話：「這格現在用的」「剛掛過，幾分內先跳過」「正在代班」。
  • API 調用記錄的角色那格不再記錯人：以前背景跑的朋友圈、記憶整理、群聊、別的角色的回覆，都被記成你當下選著的那個角色。

04備份不再被關掉

系統設置 → 備份與恢復
  • 以前 iPhone 上整合導出、雲端備份跑到最後幾 % 頁面會被系統關掉，因為打包時同時握著好幾份完整資料。現在改成邊壓邊寫：一個檔進來就壓好寫出去，資料表一批一批讀，整包寫在暫存檔裡、不留在記憶體。實測 360 張圖的備份，記憶體從多用 1.6 GB 降到 0.4 GB，時間也快了一半。
  • 還原也一樣：開備份包只讀目錄、要哪個才讀哪段；大的表一片一片寫進去；早期的單檔備份邊讀邊組；雲端還原的下載一段一段寫到暫存區。
  • 模型備份、表情包導出換成同一套。
  • 萬一還是被關掉，下次打開會認得出來，記一筆錯誤並提醒你。備份進行中，本機的排程先不跑。
  • 補上漏打包的表：行事曆、旅行、見面故事、見面預設、見面總結預設、角色小紅書主頁、購物中心以前一直沒進整合備份（還原認得，只是沒打包）。現在都帶上了，之後新增的表漏了會被測試擋下來。
  • 備份檔格式沒變，舊的備份照樣能還原。

05配角取代 NPC

朋友圈、群聊、劇情、查手機
  • NPC 搬成配角之後，只服務舊 NPC 的東西都拿掉了，神經鏈接的 NPC 分頁也收掉。
  • 朋友圈：原本 NPC 那四格改成「配角」自己一組（發文間隔、按讚、留言機率、互動延遲），舊設定讀的時候會換過來。
  • 群聊的客串、劇情的演員直接選配角。查手機加聯繫人時不再有「綁定既有 NPC」，虛構的路人照舊。
  • 舊資料的搬家和讀取都留著，備份還原不受影響。

06修好的

  • iPhone 匯出後跳預覽頁、回來畫面放大：分享前補上檔案類型；分享不成時不再自己跳下載，「備份下載」視窗多一顆「分享／存到檔案」。
  • 剛開 App、切 App 時有些樣式掉了：Tailwind 換成本地、照順序編譯的版本。
  • 小屋的生活動態卡一直出不來：情緒評估裡那段被丟掉了，現在會落成小屋的卡片。
