一個角色，
可以認識好幾個你。

身份卡不再只是換一張臉。每張卡跟每個角色各有一條自己的線：記得的事、好感、聊天紀錄都分開。卡跟卡之間可以互相認識、可以是小號；角色之間也有了自己的私聊，NPC 變成跟主角一樣的配角。生圖這邊多了畫風庫和鎖臉強度。

01關係線：每張身份卡一條線

檔案 → 身份卡；私聊右上角齒輪 → 聊天設置 → 認識的你
  • 一個角色可以認識好幾張身份卡。用哪張卡找它，就是哪一條線：聊天紀錄、記憶、好感、情緒各算各的，它不會把妹妹說過的話當成姊姊說的。
  • 訊息列表照目前的身份分，也可以切到「全部身份」一次看完；從別張卡的對話點進去，會自動換成那張卡。
  • 原本的那條是主線，以前的紀錄都在主線上，什麼都不用搬。
  • 見面、通話、主動消息 2.0、即時對話都照線走。

02身份之間的關係

檔案 → 身份卡 → 跟其他身份的關係
  • 互相認識：兩張卡可以填稱呼（例如姊姊／妹妹）。角色認識其中一張，就會知道另一個人是誰。
  • 小號：一張卡可以是另一張的小號。角色認不認得出來有三種：一直都知道、讓他發現、他察覺、你承認；否認過的他也記得。
  • 新的身份卡去認識角色，要加好友，由角色自己決定通不通過。

03群聊裡好幾個你

群組設置 → 在場的身份
  • 一個群裡可以有好幾張你的卡同時在場，打字時切換用哪張說話；一張都不選就是旁觀。
  • 每位成員照自己認識的那張卡看你，不認識的就是陌生人。

04配角與角色私聊

神經鏈接 → 配角；訊息 → 角色私聊
  • NPC 變成配角：第一次打開會自動搬過去，關係、通訊錄、群成員、朋友圈都跟著換，舊資料留著備份。配角跟主角一樣能私聊、見面、記憶，只是主動消息預設關。不想讓誰跑背景活動，可以讓他下戲。
  • 角色私聊：任兩個角色（含配角）之間有自己的對話，按「讓他們聊一輪」就聊起來，也可以冒充其中一人說一句。查手機裡原本的對話搬進來了。
  • AI 生成配角：選一位主角，讓 AI 照他的人設和世界生出身邊的人，挑喜歡的、改一改再建立。

05角色自己開小號

神經鏈接 → 角色 → 小號
  • 角色可以有小號，人設和記憶跟本人是同一個人，對外換一個名字。可以自己開，也可以讓 AI 生成；角色聊著聊著也可能自己開一個。
  • 小號會來加你好友，在訊息列表的「新的朋友」通過、拒絕或封鎖。
  • 覺得是他？可以說「我知道你是誰」，他認或不認都會記得。

06私下找人

群組設置；聊天設置 → 允許 TA 私下找別人
  • 聊到某件事，角色覺得該私下問一下，就會私聊你的某張卡，或私訊另一個角色（對方會回一句）。群聊、角色私聊、你的私聊裡都可能發生。
  • 只找得到它認識的人；一輪最多各一則；拉黑中的那條線一律不送。
  • 群聊有兩個開關，私聊在每個角色的聊天設置裡。

有用主動消息 2.0 的話，記得到設定頁重新部署一次 Worker，雲端回的訊息才帶得出私下找人。

07畫風庫與鎖臉

設置 → 生圖API
  • API 庫：存好幾組生圖 API，挑一組當全域。畫風庫：內建四套（Photographic Realism、Digital Human Render、Illustrated CG Artwork、韓系手繪插畫），也能自己寫（每次都加、畫面有人時才加、避免）。之前的半寫實 CG、精緻二次元、偽厚塗 CG 換掉了：沒改過的直接換成新的，改過的留著變成你自己的畫風。
  • 畫風照「這一次 → 角色 → 世界 → 各處畫風 → 全域」決定，每一處（聊天照片、朋友圈、頭像…）都能單獨設，也能關掉。
  • 鎖臉強度：平衡（只對長相，畫風照畫風庫）或還原（盡量像參考圖）。預設平衡；畫風被參考圖帶走時，參考圖最好也用同一套畫風的。

08資料庫生圖改版

資料庫 → 生成
  • 上面一格固定的預覽，生過的圖暫存在裝置上，跳出去也還在，存進資料庫才算數。
  • 四個分頁：想拍什麼、人物（選一個獨照、好幾個合照）、物品／風景、參數（API、畫風、尺寸、畫質、生圖預設）。
  • 可以讓 AI 幫你寫提示詞，也看得到這次真的送出去的是什麼。「誰能用」多了只有我。
