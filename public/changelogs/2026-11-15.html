SOREN S3.0 · MERIDIAN · 2026.11.14 – 11.15

手機裡多了一個
會幫你修手機的。

這一版有兩個新 App：一個是 AI 助手 Sore，問它怎麼用、哪裡壞了，也能請它直接幫你寫美化、改預設、整理世界書、做小組件；另一個是預設 App，所有預設集中在一處，私聊、群聊、電話、見面都能用自己挑的那一份。聊天紀錄也終於可以搬進搬出了。

01Sore：會幫你修手機的助手

桌面 → Sore；各處編輯頁的「請 Sore 幫忙」
  • 答疑：功能在哪、角色怎麼不回、API 報錯是什麼意思。它會自己去看你的設定有沒有填、打一次小請求測連線、翻說明。它看得到有沒有填 Key，看不到 Key 本身，錯誤訊息裡夾帶的 Key 也會先遮掉。
  • 美化：聊天白框（全域、角色、群）、氣泡、見面畫面、心象卡片、交換日記、日程卡，八處的 CSS 都能請它寫。可以傳截圖給它：「做成這樣」或「這裡跑版了」。白框、氣泡、日記、日程、心象卡片可以先預覽。
  • 預設：改條目、加條目、調參數、加正則、從內建複製一份，也能幫你設成場景預設或給哪個角色、哪個群用。這份正在被誰用，卡片上會寫出來。
  • 世界書：補條目、改觸發方式、停用、整組改名、全局啟用、掛給角色；幫某個角色寫之前會先讀他的人設（不讀聊天和記憶）。它不能刪條目，要刪請自己去世界書 App。
  • 桌面小組件：說想要什麼樣子，它寫好 HTML／CSS（可以有互動），先預覽，套用時順便放上桌面。
  • 它改的東西一律先變成一張卡片：改哪裡、改成什麼，按「套用」才寫進去；寫之前會留一份，按「還原」就回到原樣。
  • 用哪組 API 在 Sore 的設定裡選，預設用副 API（記憶宮殿那組），沒設就用全域。答疑不用太強的模型；要它看圖的話要選能看圖的。

Sore 有點嘴賤，但人不壞。它不是角色，不會進角色清單、不會進記憶宮殿。

02預設 App

桌面 → 預設
  • 原本散在見面設定、劇情劇場裡的預設集中到一個 App：通用預設（SillyTavern 格式，能匯入匯出 ST）和劇情專用預設放在一起管。
  • 每份通用預設勾「適用場景」：私聊、群聊、電話、見面。
  • 上方設場景預設：每個場景預設用哪份。角色、群自己選了的照自己的，沒選的跟著場景預設；選「內建」就是用 Soren 原本那套。
  • 「私聊／群聊／電話／見面 · 內建」都能複製一份來改。

03預設接到每個場景

聊天設置 → 預設、電話預設；群組設置 → 預設；見面設定
  • 私聊：用匯入的預設時，文風照預設；角色資料、記憶、表情包、轉帳、語音這些 Soren 的東西照常補上。預設裡放了但關掉的功能，就是不要。主動消息 2.0 和即時對話也照同一份。
  • 電話、群聊也接上了。群聊的輸出格式固定在最後，預設改不掉，長篇小說體的預設不太適合群聊和電話。
  • 預設裡的正則目前只在見面生效，私聊、群聊、電話之後再排。

04聊天紀錄搬家

神經鏈接 → 新建鏈接下的「匯入」；聊天設置、訊息列表「＋」、群組設置 → 匯入聊天紀錄；見面記錄
  • 匯入 SillyTavern 角色卡（PNG 或 JSON）：人設、開場白、卡裡的世界書一起進來，PNG 直接當頭像。
  • 匯入別家的私聊、群聊：選要接到哪個角色、哪條線，發話人對到角色；重複的可以跳過或原地覆蓋，引用回覆會接回去。匯入不會叫 AI。
  • SillyTavern 聊天（.jsonl）匯成見面故事：一份就是一場故事，思考過程收進回覆的思考裡。
  • 匯出：私聊可以匯出成 Soren JSON（能原樣匯回）或 TXT，選整段或日期區間；見面故事可以匯出成 ST 的 .jsonl。

05世界書全局啟用

世界書 → 每組底下「全局啟用」
  • 跟 ST 的全局世界書一樣，整組一鍵打開，所有角色的私聊、群聊、見面、通話、劇情都讀得到，不用一個一個掛。
  • 神經鏈接的擴展設定會列出哪幾組是全局的（只看不改，開關在世界書 App）。

06開場白與加好友

神經鏈接 → 角色 → 開場白；檔案 → 先加好友才能對話
  • 角色可以有一份開場白清單，每段勾私聊或見面：私聊空的時候角色先開口（好幾段就隨機挑），見面也從勾了見面的挑。ST 角色卡的開場白會一起進來。
  • 先加好友才能對話開關：關掉的話，點角色就直接開聊，不用送申請。
  • 新建的角色一建好就認識你現在的身份卡。

這一版不用重新部署 Worker，雲端那邊沒有改動。
