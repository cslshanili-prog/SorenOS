## P0 · 這波新邏輯，自動化測不到

### 1. XHS 分享超過一條 push 的容量

以前硬砍到 4 張，角色說分享 6 張只出來 4 張。現在改成裝不下就旁路存雲端、客戶端取回。

- **怎麼觸發**：給角色排一條 auto 任務，聊天裡先把話題引到小紅書，讓它到點時分享
  **5 張以上**筆記（筆記標題和描述越長越容易撐爆，正好是要測的場景）。
- **預期**：卡片數量和角色話裡說的一致，一張不少；每張都能點開。
- **對不上時看哪裡**：Cloudflare 實時日誌裡找 `[amsg:agentic] XHS 會話數據旁路存儲`，
  它會打出旁路前後的字節數。有這行說明 worker 側存進去了，問題在客戶端取回；
  沒有這行說明壓根沒超預算。

### 2. 刪角色會不會留下還在跑的遠端任務

- **怎麼觸發**：給角色排一條循環任務 → 刪掉這個角色。
- **預期**：刪除過程可能卡一下（在取消遠端任務），之後不再收到這個角色的推送。
- **順帶測取消失敗**：斷網狀態下刪角色 → 應該彈紅字提示「還有 N 個任務留在遠端沒取消掉」。
  之後聯網，等這條孤兒任務到點推過來 → 客戶端會自己把它清掉（不產生幽靈消息，
  日誌裡有「清理遠端孤兒任務」）。

### 3. 聊完最後一輪，同步沒成功的話會不會補上

雲端那份 fire_pack 是角色到點唯一的上下文來源，傳不上去它就會帶著舊上下文說話。

- **怎麼觸發**：跟一個掛著 AI 任務的角色聊一輪 → **立刻斷網** → 等 15 秒去抖觸發上傳
  （會失敗）→ 30 秒後恢復網絡。
- **預期**：控制台能看到 `[AmsgStateSync] flush(...) 失敗，30s 後重試（第 1/3 次）`，
  恢復網絡後重試成功，不再報錯。
- **反例（說明沒修好）**：失敗之後再沒有任何重試日誌，那份快照就丟了。

### 4. 舊 worker 會不會被誤判成最新

- **怎麼觸發**：如果手邊有台還跑著舊 bundle 的部署，連上它。
- **預期**：設置頁亮「重新粘貼部署」。貼上新 bundle 後提示消失。
- **說明**：next.4 之後加的能力上游都沒發獨立 feature flag，所以探測除了查 features
  還會比 `serverVersion`。

### 5. 處理失敗時用戶看不看得見

- **怎麼觸發**：不好造。最容易的是走上面第 2 條的孤兒路徑，或者瀏覽器 DevTools 裡
  手動把 IndexedDB 關掉再收一條推送。
- **預期**：彈出「有一條消息暫時沒能顯示，稍後會自動重試」，消息**不進聊天記錄**；
  30 秒後自動重試；連著 3 次不行才退回按原文顯示，提示改成「已按原文顯示，
  表情、卡片這些可能不完整」。

## P1 · 這波主線功能，7-18 之後沒在真機上驗過

### 6. 多任務

- 一個角色排 2-3 條任務（不同時間、不同循環方式），面板全量顯示、能逐個取消/編輯。
- 對話裡讓角色自己排一條、再讓它取消 → 面板和角色說的對得上。
- 到點後每條都按各自的時間觸發，內容不串味。

### 7. 防穿幫閘

- **正在聊天時到點**：跟角色聊著天，等一條 `expire` 任務到點 → **不該**收到推送
  （Cloudflare 日誌有 `[amsg:expire-skip]`，reason 是 `active-chat-presence`）。
- **作廢之後**：下一輪說話時，角色應該知道「剛才那條被作廢了」——可能就地把話題
  帶進來、可能續期、也可能隻字不提，但不該當沒發生過（比如原樣重發一次）。
- **force 任務**：設成「強制」的任務，正在聊天時到點也照發（鬧鐘語義）。

### 8. 服務端工具循環

- 排一條需要用工具的任務（回憶某個月的事 / 搜點什麼），確認到點時 worker 自己跑完
  工具再生成，客戶端全程不用在線。
- 副作用類的（戳一戳、轉帳、寫日記）在客戶端收到時重放。

## P2 · 順帶點一下

- **見面·加載更早**：進見面的閱讀模式，往上翻到底 → 能繼續加載更早的，翻到真沒有了
  就停住。
- **思考鏈 + 工具**：給一個開了思考鏈的角色配上工具（比如小紅書），說句話觸發工具 →
  不該再報 400。
- **小程序點單**：在麥當勞/瑞幸點單模式裡，讓角色順手排一條主動消息 → 排程應該生效，
  而不是被當成畸形調用吃掉。
- **自部署**：fork 部署倉庫 → Cloudflare 面板連上 → 填 D1 的構建變量 → Sync fork
  能觸發重新部署。

## 出問題時先看哪兒

| 現象 | 先看 |
|------|------|
| 到點沒發消息 | Cloudflare 實時日誌：`[amsg:expire-skip]` 是被閘攔了（正常），`[amsg:fire-state-missing]` 是雲端狀態不全 |
| 收到了但聊天裡沒有 | 瀏覽器控制台：post-processing 失敗會打日誌並彈提示，消息留在收件箱等重試 |
| 卡片數量對不上 | 日誌裡找「XHS 會話數據旁路存儲」，判斷是 worker 沒存還是客戶端沒取回 |
| 任務列表標「遠端不存在」 | 多半是 worker 版本舊（沒有 charId 投影），看設置頁有沒有亮「重新粘貼部署」 |
| 想看任務實時狀態 | 開發者調試面板打開「amsg2 任務觀察窗」，右上角常駐小窗有倒計時和通道 trace |
