## 1. 資料

### 1.1 `bond_entries` 表（DB v84）

拾光、心意、約定、珍藏之後的卡片都放這張表，`kind` 分開。第 2 批只用 `moment`（片刻）和 `essay`（隨筆）。

```ts
interface BondEntry {
    id: string;
    bondId: string;                 // 掛在哪段關係（bonds 的 id；空間還沒寫進 bonds 也能用，id 算得出來）
    kind: 'moment' | 'essay';       // 之後：diary / question / note / wish / promise / habit / gift / letter
    author: 'user' | string;        // 'user'＝你（哪張卡看 bondId）；角色寫的就是角色 id
    title?: string;
    text: string;                   // 片刻：發生了什麼（事實）；隨筆：角色的感想
    note?: string;                  // 片刻：你補的一句話（為什麼想留著）
    eventDate: BondEventDate;       // 事件什麼時候發生（可以不確定）
    writtenAt: number;              // 這張卡寫下的時間（隨筆可以晚於事件）
    sources: BondSource[];          // 從哪來，能點回去
    links: BondLink[];              // 跟哪件事有關（隨筆 → 片刻／記憶；後記 → 原隨筆）
    afterwordOf?: string;           // 後記：是哪篇隨筆的後記
    status: 'published' | 'draft';  // 第 2 批：片刻一律 published；隨筆生成後先是 draft，你按「收下」才 published
    favorite?: boolean;
    hidden?: boolean;               // 從時間線收起，不刪
    createdBy: 'user' | 'ai';       // 誰產生的（AI 寫的隨筆、AI 挑出來你按下收存的片刻是 'ai'）
    originalText?: string;          // 第一次被你編修前的原文（隨筆用，留著對照）
    revisedAt?: number;
    updatedAt: number;
}

type BondEventDate =
    | { precision: 'day'; date: string }                     // 2026-05-01
    | { precision: 'month'; date: string }                   // 2026-05
    | { precision: 'season' | 'period'; date?: string; label: string }  // 「春天」「剛認識那陣子」
    | { precision: 'unknown' };                              // 日期不明，可以之後補

type BondSource =
    | { type: 'message'; lineId: string; messageIds: number[]; snippet: string; at: number }  // 私聊／角色私聊
    | { type: 'date'; storyId: string; charId: string; messageIds: number[]; snippet: string; at: number }  // 見面
    | { type: 'memory'; charId: string; memoryId: string; palaceMemoryId?: string }
    | { type: 'photo'; galleryId: string };

type BondLink = { type: 'entry'; id: string } | { type: 'memory'; charId: string; memoryId: string };
```

- **`snippet` 是收存當下的原文快照**：原訊息被刪了，卡片照樣讀得到當時那段話，來源標「原訊息已刪除」。
- **`lineId`**：私聊寫 `lineKey`（主線是 charId、其他線 `charId::personaKey`，跟讀訊息同一套），角色私聊寫 `pair~A~B`。
- 備份：`bond_entries` 登記進 OSContext 的 `allStores`、欄位對照、`switch`、`importFullData`（`utils/backupStoreCoverage.test.ts` 會擋漏登記）。
- 刪角色、刪身份卡：跟 `bonds` 一起刪對應空間的卡。

### 1.2 時間線骨幹：記憶，不另存

- 身份卡 × 角色：讀這個角色的 `memories`（`MemoryFragment`），照線篩：`personaKey` 等於這段的卡；主線的卡另外收沒寫 `personaKey` 的舊記憶。
- 有 `palaceMemoryId` 的用 `resolveLinkedArchives` 讀宮殿最新正文（跟神經鏈接一樣）。
- 角色 × 角色：讀雙方通訊錄裡對方那格的 `topicBox`（角色私聊每滿 100 則整理出的話題盒，`utils/pairChatRun.ts`），兩個方向都列，標是誰的整理。
- **收藏、隱藏、補日期這些「羈絆這邊的標記」**存在 `bonds` 那筆的 `memoryMarks: Record<memoryId, { favorite?; hidden?; eventDate? }>`，不改記憶本身。記憶的正文、日期要改，走跟神經鏈接同一條路（下面 4.1）。

### 1.3 衍生登記（編修撤回對齊的底子）

紀要 4.2：修正來源、刪掉生成內容時，從它衍生的東西要一起對齊或撤回。第 2 批先把登記和工具打好：

- 每張卡的 `links` 記它「建在什麼上面」；反查用 `utils/bond/derivation.ts` 的 `dependentsOf(ref)`（誰引用了這筆記憶／這張片刻）。
- `retractEntry(id, mode)`：刪一張卡時列出依賴它的卡，讓你選「一起刪」或「留著、拆掉關聯」；拆掉後卡片上標「原本關聯的那件事已刪除」，不悄悄消失。
- 第 2 批**不寫進記憶宮殿**：片刻本來就來自已經被整理過的聊天，再寫一次會重複；隨筆是角色的感想，靠提示詞讓角色記得（第 2 節），不變成「發生過的事」。所以第 2 批撤回不用動宮殿。第 6 批「讓 AI 寫他們的故事」會產生新記憶，那時在同一個登記裡加 `palaceNode` 類型，撤回時一起刪（同一事實另有有效來源就保留）。

## 2. 提示詞：誰知道什麼

照紀要 4.1：已收存的片刻、已收下的隨筆是雙方都知道的；隨筆草稿只有作者（角色）自己知道。

- `utils/bond/prompt.ts` 的 `bondPromptBlock` 多兩小段，接在路線段後面：
  - 【你們收存的片刻】最近 8 則（照事件日期，隱藏的不算），一則一行：日期（照精度寫）＋標題或首句＋你補的那句話。標明這是「實際發生過的事」。
  - 【你寫過的隨筆】最近 3 篇已收下的，各取前 200 字，標明「這是你當時的感想，不是事實；你可以有新的想法」。
  - 沒有片刻、沒有隨筆時這兩段不出現，**提示詞一字不差**（測試鎖著）。
- 只帶這段關係自己的；別條線的卡不帶（跟記憶標線同一個原則）。
- 角色 × 角色：`buildSpeakerContext` 照同樣兩段帶（片刻雙方都知道；隨筆只帶「說話的那位自己寫的」，對方寫的不帶，因為角色之間互相不讀隨筆，讀者視角只在畫面上）。
- 改了卡（新增、編修、收下、刪除）發 `soren-bond-change`，OSContext 照舊把相關角色的雲端狀態打髒。

## 3. 收存片刻

### 3.1 從聊天收存

- **私聊**：長按訊息的選單加「收存到羈絆」；多選模式的底列也加一顆（一次收好幾則）。
- **見面**（線下故事）：訊息選單同上。
- **角色私聊**（`pair~A~B` 對話頁）：同上，收進那兩人的空間。
- 按下去開全螢幕「收存片刻」頁：
  - 上方是選到的那幾則（可以再加減前後幾則）；
  - 標題（預填空白，可以不填）、你想補的一句話；
  - 事件日期：預設是那幾則訊息的日期（照那條線的故事時間，`makeChatClock`），可以改成只到月、某段時期、或不明；
  - 「讓 AI 幫我寫一句摘要」：用副 API 把選到的訊息濃縮成一兩句「發生了什麼」（只寫事實，不加感想），你可以改；
  - 存下就是一張 `moment`，來源記訊息 id 和原文快照。

### 3.2 在羈絆裡

- 拾光分頁右上「＋」：手動新增一則片刻（沒有來源），可以附資料庫的照片。
- 「從最近的聊天挑幾件」：讀這條線最近、還沒被收存過的訊息（上次挑到哪記在 `bonds.lastMomentScanId`），用副 API 挑出 3～5 件值得留下的小事，每件附原訊息；你勾哪幾件就收存哪幾件，沒勾的不留。**不會自己默默收存**。

## 4. 時間線（拾光分頁）

### 4.1 版面

- 羈絆空間的頁首下多一列分頁：「我們」「拾光」（之後的分頁做了才出現）。
- 時間線照事件日期由新到舊，按月分段（月份是頁邊小字）；日期不確定的照精度放（「2026 年 5 月某天」「春天的時候」），日期不明的放最後一段「日期不明」。
- 每一列：日期註記、標題或首句、一個來源小標（私聊／見面／記憶／手動）、有隨筆就標「隨筆 2」。
- 篩選：全部／片刻／記憶／隨筆／收藏；「顯示收起的」開關。

### 4.2 一件事的詳細頁（全螢幕）

- 片刻：標題、發生了什麼、你補的那句話、日期（可改精度）、來源（點了跳回去，見第 6 節）、相關的隨筆清單。
- 記憶：正文、日期、情緒；「編輯」走神經鏈接同一條路（有宮殿關聯的改宮殿節點，`updateStoredMemoryNode`；沒有的改 `memories`），兩邊永遠是同一份。刪除也同一條路、同一句確認（只刪檔案記錄，宮殿節點保留）。
- 動作：讓 TA 寫隨筆、帶去聊聊、收藏、收起、編輯、刪除。

## 5. 角色隨筆

### 5.1 怎麼寫

- **指定一件事**：詳細頁按「讓 TA 寫隨筆」。
- **讓 TA 自己挑**：拾光分頁的「讓 TA 寫一篇」，從最近、還沒有隨筆的片刻和記憶裡由角色挑一件。
- **後記**：在一篇隨筆底下按「現在回頭看」，角色就同一件事寫一段新的想法，原文不動。
- 生成讀：角色人設、這段關係的路線段、印象、那件事本身（片刻或記憶）＋它的來源原文、這件事之後到現在發生過什麼（同一條線的日總結）。**只讀這條線的**，別條線的不進來。
- 寫法：第一人稱、寫「我怎麼理解這件事」；推測要寫成推測（「我猜她那天有點失望」），不能把感想寫成事實，也不能新增沒發生過的事（紀要 4.2）。長度照角色個性，不硬湊字數。
- 生成完是**草稿**：你看過按「收下」才變成已收下（這時角色才「記得自己寫過」，進提示詞）；不喜歡可以重寫或丟掉。

### 5.2 讀與改

- 隨筆頁是書頁排版：標題、「寫於 11 月 26 日 · 關於 5 月 1 日那件事」、正文、後記依序接在下面。
- 重開就是讀存好的原文，不重新生成。
- 你可以編修，第一次改的時候把原文留在 `originalText`，頁面上可以看「原本的版本」。

## 6. 來源回連、帶去聊聊

### 6.1 跳回那則訊息

- 新的一次性字條 `chatJumpLaunch`（`utils/appLaunch.ts`）：`{ charId, personaKey?, messageId }`。私聊收到後載入那則訊息前後一段（不是只有最近 N 則），捲到那裡、閃一下標記；往上往下照常可以繼續載入。`appReturn` 讓你按返回回到羈絆。
- 見面：`dateJumpLaunch`：開那場故事、捲到那則。
- 角色私聊：開那兩人的對話頁、捲到那則。
- 記憶：開神經鏈接那個角色的記憶分頁（有宮殿關聯也可以開記憶宮殿）。
- 原訊息已刪：不跳，卡片上直接顯示收存時的原文快照。

### 6.2 帶去聊聊（私聊）

- 卡片上的「帶去聊聊」：開這條線的私聊，輸入框上方掛一張「帶過來的卡」（片刻／記憶／隨筆的標題和摘要），你打一句話一起送出。
- 送出的訊息照舊是 `type: 'text'`，多 `metadata.bondRef: { entryId?, memoryId?, kind, title, excerpt }`；氣泡上方顯示那張小卡，點了回到羈絆的那件事。
- 歷史和記憶裡寫成 `[從羈絆帶來：〈片刻〉標題——摘要] 你說的話`，角色看得懂你在說哪件事、怎麼接隨角色。
- 雲端（即時對話、主動消息）照同一個格式送，不用改 Worker。
