# 資料庫生圖改版＋編輯框全螢幕

> 狀態：第 4 節定案（Liora 2026-11-13），**已做**。起因：設置頁編輯畫風時被黏住的保存鈕擋住、框太小；資料庫生圖生了沒存一跳出去就沒了，版面也要照查手機的風格重排（Liora 給了三張參考圖）。

## 1. 編輯框全螢幕

- 共用元件 `components/common/ExpandableTextarea.tsx`：一般的多行輸入框，右上角一顆「⤢ 全螢幕」，點了蓋滿整個螢幕編輯（上面標題、字數，下面「完成」），完成就回填。之後 Soren 其他編輯框一個個換成它。
- 這次先換：設置 → 生圖API 的畫風三格（每次都加／畫面有人時才加／避免）。
- 保存鈕不再黏在底部（就是它擋住編輯框）：
  - **畫風庫改成改了就存**（跟角色編輯頁一樣），不用按保存。
  - API 那幾格照舊按「保存配置」，鈕放回 API 那一區底下。

## 2. 資料庫生圖（照參考圖，查手機的深色風格）

由上到下：

1. **預覽框**：最上面一大格。還沒生成時寫「選好 API 與提示詞，點『生成』」；生成中轉圈讀秒（現在那個）；生好顯示圖，右上角下載。
2. **這次生的縮圖列**：每生一張就多一格，點了換到預覽框，長按／點垃圾桶刪掉。**暫存在這次開著的 App 裡**：跳出資料庫、去別的 App 再回來都還在；把 App 關掉（重新整理）或自己刪掉才會清。
3. **四個分頁**：
   - **想拍什麼**：一格描述。底下開關「AI 幫我寫提示詞」（寫明會多一次 API）：開著時先讓 AI 照你的關鍵字寫成完整的提示詞再生圖。
   - **人物**：這次拍誰，點選頭像（你也算一個）；選一個＝獨照，選好幾個＝合照，都不選＝沒有人。
   - **物品／風景**：見第 4 節 1。
   - **參數**（都選填，不選照設定）：這次的 API、這次的畫風（選了下面列出那幾段提示詞可以改，改完可以「另存成新畫風」或「覆寫這套」）、尺寸、畫質；最下面「把這組存成生圖預設」。
4. **這次送出的提示詞**：可收起。每次生成後顯示真的送出去的那段（AI 寫的、加了畫風的都看得到）。
5. **底部**：張數 − 1 ＋（一次生幾張）、「生成」，有圖時多一顆「存進資料庫」。
6. **存進資料庫**（另一頁，參考圖 3）：預覽、**名字**、描述（AI 寫，可以選用哪組 API）、誰能用（所有人／照世界／指定身份／指定角色＋頭像），「存進資料庫」。

## 3. 生圖預設

一組「API＋畫風＋尺寸＋畫質」存成一個名字，參數分頁一鍵套用。存在 `imageGenConfig.genPresets`，設置 → 生圖API 也看得到、能刪。

## 4. 定案（Liora 2026-11-13）

1. **跟現在一樣**：拍人（選了人物）用「想拍什麼」那格寫動作場景；「物品／風景」分頁裡有自己的「想拍什麼」和物品／風景二選一。差別只是上面多了固定的預覽框。生成時照你現在停在哪一類（人物那兩頁＝拍人，物品／風景那頁＝拍東西）。
2. 一次最多 **4 張**，一張一張排著生。
3. 暫存**存在裝置上**，只有自己刪才清；縮圖列有「全部刪除」。存進資料庫的那張標「已存」，在暫存刪掉不動資料庫那份。
4. 「誰能用」多一個**只有我**（角色都不能用、不列給角色）；參考圖上的「指定身份」不做。**人物**分頁開著關係線時把你的每張身份卡都列出來（合照可以選好幾張）。
5. **不加名字**欄位（描述就夠，角色讀的也是描述）。
6. 生圖預設先只在資料庫生圖用。

## 5. 實作拆法（草稿）

- **a**：全螢幕編輯框元件、設置頁畫風庫改成改了就存、保存鈕歸位。
- **b**：資料庫生圖新版面（預覽、暫存縮圖、四個分頁、AI 寫提示詞、張數、這次送出的提示詞）。
- **c**：參數分頁（API／畫風改寫另存覆寫／尺寸畫質）、生圖預設、存進資料庫頁（名字、身份）。

## 6. 實況

- `components/common/ExpandableTextarea.tsx`：右上角「⤢」全螢幕編輯，完成才回填（取消不動）；`tone="dark"` 給深色頁。已換：設置頁畫風三格、資料庫生圖的想拍什麼／物品風景／參數裡的畫風三格、存進資料庫的描述。
- 設置頁：畫風庫、全域畫風、各處畫風**改了就存**（停 0.5 秒寫一次，只寫這幾欄）；「保存 API 設定」放回 API 那一區底下，不再黏在底部。生圖預設在這裡列出、可刪。
- `utils/libraryGenDrafts.ts`：暫存清單在 localStorage（`soren-library-gen-drafts-v1`），圖存成 blobRef；最多 40 張，超過先丟最舊的已存過的、再丟最舊的。刪掉沒存過的那張才清 blob。
- `components/library/LibraryGenerateView.tsx` 重寫（深色）：自己的標題列（Gallery 不再畫）；預覽＋縮圖（已存打勾、選中那張可刪、全部刪除）＋下載；四個分頁；拍哪一類照停在哪一頁（人物兩頁＝拍人、物品／風景＝拍東西），按鈕上寫「生成（合照）」；「AI 幫我寫提示詞」開關記在裝置上，一批只寫一次（`writeLibraryPromptWithAI`，主對話 API）；張數 1～4 一張張排；「這次送出的提示詞」顯示 `generateImage` 回傳的 `sentPrompt`（套了畫風之後）。
- 參數：生圖預設一鍵套用；API；畫風（選了某套就抄一份出來改，改過就用 `styleOverride` 照改過的生，可另存成新畫風或覆寫）；尺寸、畫質（`generateImage` 的 `size`／`quality` 覆蓋那組 API）；「存成生圖預設」（`imageGenConfig.genPresets`）。
- 人物：開著關係線時每張身份卡各一顆（subject key `user:身份鍵`），關著照舊一個「你」。
- 存進資料庫：另一頁（米色）；描述（AI 寫）、誰能用多了「只有我」（`LibraryAccess` 的 `none`：`canCharUseLibraryImage` 回 false）；存完留在生圖頁，那張標已存。只拍你的照片預設照舊「所有角色共用」，要只留給自己就選只有我。
