## 1. 「他們」首頁

角色之間的空間第一個分頁從「我們」改叫**他們**（分頁列 `bondTabsFor('pair')`）。由上而下：

1. 主視覺（兩人頭像、路線與階段、天數）——第 1 批已有。
2. **他們的故事**（新）：最近一章的標題與開頭兩行，「讀下去」開全螢幕閱讀頁；下面一行「寫下一章」「全部章節（N）」。還沒有故事時是一張邀請卡「寫他們的第一個故事」。
3. **讀者視角的概覽**（新）：一段 150～300 字、像書背文案的「他們的故事走到哪了」，第三人稱、只寫已經發生的（故事、拾光、約定、私下聊天的整理）。按「更新」才重寫（不自動），寫的時候拿全部章節的摘要＋時間線＋約定＋私聊話題盒。存在 `bonds.pairOverview`（文字＋寫的時間＋當時讀到第幾章）；有新章節時旁邊亮一個「有新章節，可以更新」。
4. 此刻的他們、他們怎麼看對方、下一個紀念日——第 1 批已有，不動。
5. 自動日記開關（已有），文案改成「他們私下聊了一大段、或存下一章故事時，各自留一篇日記」。

## 2. 讓 AI 寫他們的故事

### 2.1 寫故事頁（全螢幕）

| 欄位 | 說明 |
|---|---|
| 方向 | 一句話，可空（「第一次一起出門旅行」「為了一件小事冷戰」）。空的時候 AI 照前情自己往下寫一件日常 |
| 場景 | 快選：日常、約會／出遊、節日、吵架和好、意外、深夜談心、自訂（選了只是加進方向，不是硬分類） |
| 視角 | 旁白（第三人稱全知，預設）／A 的視角／B 的視角 |
| 篇幅 | 兩格「大約幾字到幾字」，預設空、placeholder 寫「像 1200～2000」；**第一次寫要你填**（照第 5 批信的做法：數字讓你自己選），之後記住這個空間上次填的 |
| 文風 | 文字框（右上能全螢幕寫），存成這個空間的預設文風 |
| 接著哪一章 | 預設接在最新一章後面（帶前情）；也能選「獨立一篇」（不帶前情摘要，只帶時間線） |

按「寫」→ 草稿出來（閱讀排版），底下：**重寫**（同設定再寫一次，舊稿留在「上一版」可切回）、**改**（全螢幕編輯）、**丟掉**、**存下**。只有存下才算數、才回寫。

### 2.2 寫的時候帶什麼（提示詞）

- 兩人的人設（`charIdentityLines`／人設本體，小號照 `altPersonaView`）、世界與曆法、各自的說話語言。
- 這段關係：路線、階段、稱謂、天數；**友情、親情鎖定照樣放在最後**（`bondFinalLock`，硬規則第 2 條）。
- 他們怎麼看對方（`relationships`）、通訊錄好感、此刻的他們。
- 前情：之前各章的摘要（存下時順手寫一段 80～150 字摘要存在章節上）、最近一章全文（篇幅超過就只帶尾段）。
- 時間線：拾光（話題盒整理、片刻、收存的里程碑）、約定、禮物、信——都是「已經發生的」，讓故事不跟它們打架。
- 最近的私下聊天（角色私聊線最後 40 則）。
- 規則：只寫這兩人（可以帶路人、配角當背景，但不替你／身份卡說話——**你不在場**，故事裡不出現用戶）；不寫成大綱、不寫後記；不改路線；事實要跟前情一致。

### 2.3 存下：回寫各區（先列清單、你勾）

存下時，副 API 讀這一章，抽出「故事裡真的發生的事」，列成一張全螢幕清單（照第 2 批「挑幾件」的做法，**你勾了才寫**，預設全勾）：

| 抽出的東西 | 寫到哪 | 說明 |
|---|---|---|
| 片刻（1～3 件） | 拾光，`moment`，來源記這一章 | 事實，第三人稱 |
| 里程碑（第一次約會、告白、和好……） | 約定 › 里程碑 | 有階段轉折的另外出承認卡（2.4） |
| 願望、約定、默契 | 約定 | 狀態直接是「成立」（故事裡已經說好了），默契兩邊都認 |
| 禮物 | 珍藏 › 禮物（手記，誰送誰、什麼、場合） | 只呈現結果 |
| 信 | 珍藏 › 信件（全文由那個角色另外寫，不從故事裡剪） | 故事裡寫了「他留了一封信」才有 |
| 日記 | 心意 › 日記：A、B 各一篇（主觀、第一人稱、寫自己怎麼看這件事） | 自動日記開關關掉時預設不勾 |
| 記憶 | A、B 各一條第一人稱話題盒記憶＋記憶宮殿（開了才送），標「這是你跟某某之間發生的，用戶不在場」 | 跟私下聊天整理同一條路（`sendPairTopicsToPalace`） |

清單每一項能改字、取消勾。全部寫完，衍生物都登記在這一章名下（`utils/bond/derivation.ts`，第 7 節）。

### 2.4 關係轉折要你承認

抽出的里程碑如果是會改階段的那種（照第 4 批 `SYNC_KINDS`：在一起、求婚、結婚、和好、絕交……），不直接改，首頁出一張承認卡「這一章裡他們〈在一起了〉，要記成他們現在的階段嗎？」——按「對」改階段（路線不動；路線不允許的轉折不會出現，例如友情線不會抽到「在一起」，抽到也丟掉）、記里程碑、可選加紀念日；按「不是」只留片刻。

### 2.5 章節

- 存在 `bond_entries`，新 kind `story`：`title`、`text`（全文）、`story: { chapter, pov, direction?, scene?, words?, summary, prevId?, standalone?, extractedAt? }`。
- 章節目錄（全螢幕）：章號、標題、日期（故事日期——可以填，預設寫的那天）、摘要；長按排序不做，順序照章號。
- 閱讀頁：閱讀排版，上一章／下一章，「帶去聊聊」**不做**（你不在場，跟哪個角色聊都不對）；右上「改」「刪」「重新整理回寫」。

## 3. 各區分頁（角色之間版）

分頁列：**他們｜拾光｜心意｜約定｜珍藏**（五個，跟身份卡 × 角色一樣寬）。共同原則：**只呈現結果＋小按鈕**，你能改字、能刪，不能用自己的名義新增（作者是他們）；里程碑例外，可以手動補（你是讀者也是史官）。

### 3.1 拾光

照舊（話題盒整理＋片刻＋隨筆），多一種來源「故事」，點了開那一章。

### 3.2 心意：日記、問答

- **日記**：清單照日期，作者 A 或 B，閱讀排版。小按鈕「讓 A 寫一篇」「讓 B 寫一篇」：只寫最近發生的（最近一章、最近的私聊整理、最近的片刻），沒有新東西時照實寫「沒什麼特別的一天」那種。日記存 `bond_entries` 新 kind `diary`（`author` 是角色 id、`diary: { date }`）——**不用交換日記那張表**，那張是你跟角色交換的。
- **問答**：「讓他們回答一題」：你出題、或 AI 照他們的關係推薦三題選一題；兩人各自作答（各自看不到對方的答案，照人設寫），答完一起揭曉——你是讀者，揭曉是給你看的演出。沿用 `question` kind，`asker: 'user'`、兩邊 `answers`。
- 沒有心靈角落（紀要）。

### 3.3 約定：願望、約定、默契、里程碑

- 都從故事抽出來（2.3）；狀態只呈現，沒有完成判定、沒有積點。
- 你能改字、刪除；里程碑能手動補（「補一個里程碑」，跟身份卡那邊同一頁，作者記成「讀者」）。
- 小按鈕「讓 A 說一個願望」：照人設與前情寫一個 A 想跟 B 做的事（只存成願望，不推劇情）。

### 3.4 珍藏：禮物、信

- **禮物**：故事抽出的、他們之間的；圖鑑同一個樣子（禮物盒），沒有「打算送」、沒有購物中心（角色之間的購物中心單不存在）。
- **信**：小按鈕「讓 A 寫一封信給 B」（就已經發生的事寫，可以補一句方向）；B 可以「回信」（再按一次讓 B 寫）。信封、蠟封、拆信動畫同一套；沒有慢寄（讀者視角，寄出就到）。
- 沒有留給以後（紀要沒有；他們要「封給以後」可以寫在故事裡）。

## 4. 他們私下聊滿一大段：各留一篇日記

`utils/pairChatRun.ts` 的 `archivePairIfNeeded` 每 100 則整理一次時，如果這段關係的 `pairAutoDiary !== false`、兩人都在戲上（`isOnStage`），各寫一篇日記（3.2 那種），日期是那段聊天最後一則的故事日期，來源記那段的話題盒 id。空間還沒寫進表（虛擬空間）時，第一次寫日記就寫一筆 `bonds`。

## 5. 記憶與提示詞

- **他們私下聊天**（`relationshipChat` 的 `pairContext`）：已經帶片刻、隨筆；這批多帶「你們之間的故事」（最近三章的摘要＋全部章節的一行目錄）、日記（只帶自己寫的最近兩篇）、約定（成立的願望、約定、默契、里程碑）、禮物與信的一行。沒有內容時一字不差。
- **各自跟你聊天**：「你私下跟別人聊的」那段（關係線第 6 批 6d）多一行「你跟 B 之間最近發生的事：〈最近一章摘要〉」——只寫事實摘要，不帶日記；照 6d 的規矩，角色可以自己決定要不要跟你提。
- **記憶宮殿**：每章存下時送一條（2.3），內容是那個角色第一人稱的摘要，標籤 `角色故事`＋對方名字，`storyId` 記在節點上，撤回時照它刪。

## 6. 讀者視角的規矩

- 故事、日記、問答、信是**他們的世界裡發生的**，所以雙方都知道（片刻、故事、里程碑、禮物）；日記、問答答案、信是各自寫的，照第 2 節知情範圍：日記只有作者自己知道，信收件人知道，問答揭曉後雙方都知道。
- 你（身份卡）**不在場、也不知道**：這些不進任何身份卡 × 角色的空間；角色跟你聊天時只透過第 5 節那一行，像他自己提起一件私事。
- 你改了字的地方，角色記得的是改過的版本（跟第 2 批隨筆編修同一個規矩）。

## 7. 刪改一章

- **刪一章**：照 `utils/bond/derivation.ts` 列出這一章長出來的東西（片刻、里程碑、願望、約定、默契、禮物、信、日記、話題盒、記憶宮殿節點），選「一起刪」或「留著，拆掉跟這章的關聯」；承認卡已經改過的階段**不回退**（另外提醒你可以去路線頁改）。
- **改內文**：存了之後問一次「內容改了，要不要重新整理回寫？」——「要」＝把這章的衍生物列出來讓你選刪哪些，再照新內文抽一次清單；「先不要」＝只改字（摘要也問要不要重寫）。
- 衍生登記多兩種類型：`topic`（話題盒那條，`charId`＋`topicId`）、`palaceNode`（`charId`＋節點 id）；同一事實另有有效來源時保留（第 2 批的規矩）。

## 8. 資料

```ts

    chapter: number;
    pov: 'narrator' | string;     // 旁白或角色 id
    direction?: string;
    scene?: string;
    words?: [number, number];
```

不開新表（都在 `bond_entries`、`bonds`），備份照舊帶。

## 9. 埋點（照 `docs/analytics.md`）

- `羁绊故事`：`{ 动作: 写|重写|存下|丢掉|改|删, 视角: 旁白|角色, 场景: 日常|约会|节日|吵架和好|意外|深夜|自订 }`
- `故事回写`：`{ 片刻, 里程碑, 约定类, 礼物, 信, 日记, 记忆 }` 各是「勾了几件」的分档（0／1／2+），存下回寫時發一次
- `角色之间小按钮`：`{ 动作: 日记|问答|写信|回信|愿望|里程碑 }`
- `更新关系概览`（無屬性）
- `收存拾光片刻` 的來源多「故事」；`同步承认关系` 的來源多「故事」。

## 10. Liora 的決定（2026-11-27：全部照建議）

以下是當時的題目與建議，留著對照：

1. **故事在哪寫？** 建議**羈絆裡一次寫一章**（像翻一本書，寫完存下才回寫）；不用劇情 App 的一來一回演出——劇情要你在場或當執筆者一句句推，跟「讀者看他們的故事」是兩種體驗。
2. **存下時回寫各區，自動還是你勾？** 建議**列清單你勾、預設全勾**（跟「挑幾件」一樣）；全自動的話一章常常會長出你不想要的約定或禮物。
3. **故事算不算真的發生過？** 建議**算**：進兩人的記憶（話題盒＋記憶宮殿），他們之後私下聊天、各自跟你聊天都記得，標「用戶不在場」。不算的話就只是一篇小說，角色不會提。
4. **故事能不能推進他們的關係階段？** 建議**能提議、你承認才改**（承認卡）；路線照硬規則只有你能改，友情、親情鎖定在寫故事時照樣鎖。
5. **篇幅與文風**：建議跟第 5 批的信一樣**第一次寫要你自己填字數**，不給預設數字；文風框存成這個空間的預設。
6. **角色之間的分頁**：建議**他們｜拾光｜心意｜約定｜珍藏**，都是只呈現結果＋小按鈕，你能改字、能刪，不能用自己的名義新增（里程碑例外）；不做等級積點、親近信任、心靈角落、留給以後。
7. **問答要不要盲答？** 建議**各自作答、答完一起揭曉**（你看的是揭曉的那一刻；他們彼此在揭曉前看不到）。
8. **信要不要慢寄？** 建議**不要**：讀者視角，寄出就到；要「等很久才收到」可以寫進故事裡。

## 11. 分四小批做，最後一個 PR

1. **6a 故事**：`story` kind、寫故事頁（方向、場景、視角、篇幅、文風、接續）、草稿／重寫／改／丟掉／存下、章節摘要、章節目錄與閱讀頁、「他們」首頁的故事區、讀者視角概覽（更新）、提示詞（帶前情、時間線、鎖定），測試。
2. **6b 回寫**：抽取清單（片刻、里程碑、願望約定默契、禮物、信、日記、記憶）、你勾了才寫、衍生登記、話題盒＋記憶宮殿、承認卡（故事來源）。
3. **6c 各區分頁與小按鈕**：角色之間的心意（日記、問答）、約定、珍藏；小按鈕（日記、問答、寫信回信、願望、補里程碑）；私聊滿 100 則自動日記。
4. **6d 收尾**：刪改一章的撤回與重新整理、提示詞（他們私聊、各自跟你聊）、埋點、Sore 知識、AGENTS／bond.md／todo、驗證（tsc／vitest／Playwright）、PR 到 dev。
