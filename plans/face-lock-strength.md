# 鎖臉強度

> 狀態：**設計稿，等 Liora 定第 5 節**（2026-11-13）。起因：鎖臉一開，畫風常被參考圖帶走（寫實參考圖配二次元畫風，出來還是寫實）。Liora 想要能調「多像參考圖」。

## 1. 現在怎麼鎖臉

所有入口（聊天照片、朋友圈、見面拍下這一刻、資料庫生圖……）都走 `utils/imageGeneration.ts` 的 `generateImage`，帶了參考圖就打 OpenAI 相容的 `/images/edits`。這條路有兩個固定做法：

- 提示詞最後**寫死一段 `[參考圖約束]`**：「臉型、五官比例、膚色、髮型需與參考圖保持高度一致，不要更改容貌特徵」。等於永遠是最強的那一檔。這段沒提畫風，模型就連畫風一起照抄。
- 失敗就往下退：多張 → 只送第一張 → 純文字。原因記在 `referenceError`。

資料庫生圖另外多寫了一句「畫法、質感照畫風」（#172），其他入口沒有。

## 2. 用的人用什麼

Liora 看的數據：GPT-Image 系列約七成，Google 約兩成，其他約一成。大家**都經過自己的中轉站**，中轉站各家不一樣：同一個參數，這家收、那家可能報錯，也可能收了不傳下去（靜悄悄被丟掉，我們看不出來）。

## 3. 三檔，不做 0～100

| 檔位 | 提示詞（`[參考圖約束]` 換成） | GPT-Image 多送 |
|------|------|------|
| **還原** | 臉、髮型、膚色、身形都照參考圖，盡量像同一個人（現在的寫法） | `input_fidelity: high` |
| **平衡**（預設） | 只對長相（臉型、五官、髮型髮色）；畫法、質感、光線照畫風，不照抄參考圖的畫風 | 不送 |
| **偏畫風** | 大致認得出是同一個人就好，畫風優先，五官可以照畫風的畫法改 | 不送（OpenAI 預設就是 low） |

- 做 0～100 會讓人以為每一格都有差，其實只有提示詞在變，三檔老實。
- `input_fidelity` 是 OpenAI 圖片編輯介面的參數（`high`／`low`，預設 low）。只有 GPT-Image 系列有，而且**要先實測**：Liora 的中轉收不收、會不會傳下去。偏畫風跟平衡在參數上一樣，差在提示詞。
- **預設改成平衡**：等於所有入口的 `[參考圖約束]` 都從「高度一致」換成「只對長相、畫風照畫風」。這會改變現有用戶的出圖（畫風會拉開、臉可能沒那麼死像）。

## 4. 中轉不收參數怎麼辦

- **只在模型名有 `gpt-image` 時送**。Google 和其他家只換提示詞。
- **送了報錯 → 拿掉參數再送一次**（在現有的「多張 → 單張 → 純文字」之前）。成功就在那組 API 上記「這家不收 input_fidelity」，之後不再送，也不再白打一次。
- **收了但丟掉**我們偵測不到。所以畫面上不說「已調強度」，只說「這組有送強度參數」或「只用提示詞」。
- API 設定裡多一個開關「送鎖臉強度參數（GPT-Image）」，預設照模型名自動。中轉每次都報錯、或用戶覺得怪的，可以自己關。被自動記成不收時，這裡也顯示出來，能手動重設。

## 5. 待定

1. **設在哪裡**：建議**每個角色（和身份卡）一個預設檔位**，放在「專屬生圖設定」參考圖下面；資料庫生圖的參數分頁可以這次另選。聊天裡按重新生成那個編輯框要不要也能選？建議先不要，照角色的。
2. **預設檔位**：建議**平衡**。這會改變現有用戶的出圖（第 3 節最後一點）。要保守的話，舊用戶維持還原、新角色才預設平衡。
3. **合照兩個人檔位不同**：建議照最強的那個人（例如一個還原、一個平衡，就整張用還原），因為參數只能送一個值。
4. **偏畫風要不要做**：GPT-Image 上它跟平衡的參數一樣，只差提示詞，效果可能不明顯。可以先只做還原／平衡兩檔，實測不夠再加。

## 6. 拆法（草稿）

- **a**：三段提示詞、角色檔位欄位、`generateImage` 收 `faceLock`、合照取最強。
- **b**：`input_fidelity`（模型名判斷、報錯重送、記在那組 API、設定頁開關）。先用 Liora 的 API 實測。
- **c**：UI：專屬生圖設定的檔位、資料庫生圖參數分頁、鎖臉說明那行帶上「有送參數／只用提示詞」。
