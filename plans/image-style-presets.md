# 生圖畫風庫與 API 庫

> 狀態：**設計稿**，第 6 節 1、2 已定（Liora 2026-11-12），3、4 待定。起因：第 6 批 AI 生成配角時發現 Soren 沒有「畫風」可選，只能每次手填「這次的風格」。

## 1. 現在的樣子

- **設置 → 生圖 API**：一組 API（URL、Key、模型、尺寸、品質），下面一格「補充提示詞」，拼在**每一次**生圖的最後（`imageGenConfig.extraPrompt`，`utils/imageGeneration.ts` 的 `generateImage`）。想統一畫風只能寫在這格，全手機一套，畫風和畫質混在一起。
- **角色**：`imageGenCharConfig` 管的是長相：參考圖鎖臉、人物特徵提示詞。
- **AI 生成配角**：一格一次性的「這次的風格」，不存。
- 生圖走 OpenAI 相容的 `/images/generations`（帶參考圖走 `/images/edits`），**沒有負面提示詞欄位**。

## 2. 要做到什麼

- 存好幾套**畫風**（名字＋提示詞），存好幾組**生圖 API**，各挑一個當全域預設。
- 世界（神經鏈接分組）可以指定畫風：古風世界、賽博世界各自一套。
- 角色可以指定畫風，沒指定就跟世界、再跟全域。
- 每一種會生圖的地方可以各自設：關閉／跟全域／某一套畫風。
- 在生圖的地方就能臨時換，不用每次回設置頁。

## 3. 畫風庫

一套畫風：

```ts
interface ImageStylePreset {
  id: string;
  name: string;
  /** 每次都加的：畫風、質感、光影、色調 */
  prompt: string;
  /** 畫面裡有人時才加的：臉、皮膚、構圖（特寫、自拍視角…）；拍食物、風景時不加 */
  portraitPrompt?: string;
  /** 負面提示詞：預設寫成「避免：…」接在正文後面；API 那組勾了「支援 negative_prompt」才改成欄位送 */
  negativePrompt?: string;
  /** 這套畫風固定用哪組 API（選填；沒填跟全域） */
  apiId?: string;
  builtin?: boolean;
}
```

- **為什麼拆「有人時才加」**：群裡常用的這幾套都寫了「人物位於構圖主體、臉部特寫、自拍視角」，套到朋友圈的咖啡、窗外夜景、資料庫的物件圖，就會硬塞一張臉。判斷「畫面裡有沒有人」沿用現成的 `looksLikeSelfieDescription`（參考圖鎖臉就是靠它決定帶不帶）。
- **負面提示詞**：現在的接口沒有這個欄位。預設當文字接在後面（「避免：…」）；有些中轉站收 `negative_prompt` 欄位，在 API 那組勾一下才送，不勾不送，免得嚴格的接口直接 400。
- **內建**：3～4 套，可以改、可以刪、可以「恢復內建」。見第 6 節。
- **原本的「補充提示詞」**：搬進畫風庫變成一套「我原本的補充提示詞」，設成全域預設；行為跟現在一模一樣，那一格之後就不見了。沒填過的人不搬。

## 4. 生圖 API 庫

- 現在那一組變成庫裡的第一組，可以再加幾組（不同中轉、不同模型），挑一組當全域。
- 「允許生圖」「允許角色自己發照片」兩個總開關照舊，在庫外面。
- 這組支不支援參考圖、支不支援 `negative_prompt`，各自記在那一組上。

## 5. 誰用哪一套（解析順序）

| 層 | 設在哪裡 | 說明 |
|----|---------|------|
| 這一次 | 生圖的地方臨時選 | 資料庫生圖、AI 生成配角、小號頭像、聊天照片的「✎ 改提示詞」重生，都多一個下拉，預設是下面解出來的那套 |
| 角色 | 角色編輯頁「生圖」那一區（鎖臉旁邊） | 小號跟著本人 |
| 世界 | 神經鏈接分組 | 這個世界的人都用這套 |
| 功能 | 設置 → 生圖 → 各處畫風 那張表 | 聊天照片、朋友圈、穿搭、見面拍照、頭像、資料庫，各一格：關閉／跟全域／某一套 |
| 全域 | 畫風庫裡挑的預設 | |

- 越上面越優先；某一格是「關閉」就不生圖，誰也蓋不過。
- 跟角色無關的圖（資料庫裡你自己叫 AI 生的）不看角色和世界，只看功能那格和全域。

## 6. 定案與待定

1. **已定**：解析順序照第 5 節（這一次 > 角色 > 世界 > 功能那格 > 全域，「關閉」最大）。
2. **已定**：拆「有人時才加」。內建的幾套都是針對人像寫的，臉、皮膚、構圖那幾句放進 `portraitPrompt`。
3. **待定**：內建四套（草稿）：
   - 半寫實 CG：3D、真人膚質、寫真感（群友 1）。
   - 精緻二次元：2D 數位插畫、動漫式眼睛高光、霧面瓷肌（群友 3；跟群友 2 幾乎同一套，留一個）。
   - 偽厚塗 CG：韓系乙女 CG、言情小說封面感，描邊清楚、明暗極低、近白灰、啞光（群友提供）。
   - 韓系手繪插畫：看得出手繪痕跡的鉛筆線稿＋水彩／不透明水彩、紙紋、留白（我寫的草稿，跟偽厚塗拉開：不是數位 CG）。
   - 群友 2 那份貼上來時夾了一串零寬字元（看不見），做內建時清掉。
4. **待定**：一套畫風可以「偏好」某組 API，但不鎖死——那組失敗（連不上、5xx、401／403、額度）就自動改用全域那組重試一次，提示一聲；生圖地方的臨時下拉也能選 API。這樣 API 掛了不用回設置。

## 7. 實作拆法（草稿）

- **a**：畫風庫、API 庫的資料與搬遷（原本的補充提示詞搬成一套）、設置頁的兩個庫、全域預設、解析函式（純邏輯，一處定義）。
- **b**：各處畫風那張表、角色／世界的指定、所有生圖入口改走解析函式。
- **c**：生圖地方的臨時下拉；資料庫生圖的預覽框（按下去頁面沒反應那個）另外排。
