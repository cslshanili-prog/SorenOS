# 雙向拉黑＋臨時會話 設計文件

路線圖第 4 項最後一批。

> **2026-09-25 定案**
> - 兩個方向都做：用戶拉黑角色、角色拉黑用戶。
> - 用戶拉黑角色時，角色的訊息**一律進不來**，也不給偷看——製造懸念。唯一的縫是第二批的臨時會話。
> - 臨時會話＝拉黑期間的後門：雙方每天各 **3 次**、每次最多 **50 字**（之後做成可調）。
> - 原本「角色拉黑你 → 送好友申請附驗證訊息」**併進臨時會話**：你在臨時會話說的每一句，角色讀完一起決定回不回、解不解除。
> - 分兩批：第一批是拉黑本身，第二批是臨時會話。

## 資料

角色上的三個欄位：

```ts
interface ChatBlockState {
    by: 'user' | 'char';
    /** 開始拉黑的時刻 */
    since: number;
    /** 角色拉黑時說的原因（給用戶看不到，給角色自己記得為什麼） */
    reason?: string;
    /** 角色拉黑時：下一次「要不要解除」的判斷時刻 */
    reconsiderAt?: number;
}

chatBlock?: ChatBlockState;            // 現在的拉黑；沒有就是沒拉黑
chatBlockLog?: Array<{ by; since; until; reason? }>;   // 解除過的拉黑，最多留 20 段
allowCharBlockUser?: boolean;          // 聊天設定 Scenario：允許角色拉黑你（預設關）
charBlockCooldown?: 'short' | 'normal' | 'long';       // 角色消氣要多久
```

「這則訊息是不是被拒收的」不另外存：**用戶的訊息時間落在某一段「角色拉黑你」期間，就是被拒收的**。這樣文字、圖片、貼圖、轉帳…所有種類的訊息都自動算進去，不用去改每一條發送路徑。

## 一、用戶拉黑角色

- 聊天設定頁最下面一顆「拉黑 TA」，二次確認；拉黑中變成「解除拉黑」。
- 拉黑中：
  - 聊天頁輸入框換成一條「你已把 TA 拉黑・解除拉黑」。
  - 角色什麼都不會生成：主動訊息 1.0（含延遲回覆的背景路徑）、雲端主動訊息 2.0、延遲自動回覆、全域 2 秒自動回覆、手動 ⚡ 都擋。
  - 雲端：fire_pack 帶 `chatBlocked: true`，Soren Worker 到點直接跳過（記一筆 skip，不花 token、不推播）；舊 Worker 不認這個欄位，客戶端收件時再擋一次（吞掉，跟防穿幫閘同一個出口）。雲端任務本身不刪，解除後照常。
  - 朋友圈：拉黑就不算朋友（設計文件「拉黑優先」那條），互相看不到；被拉黑的角色也不自動發文、不被「↻」挑中（發了你也看不到，白花 API）。
- 拉黑、解除時各落一行系統提示（角色看得到）：「你把 X 拉黑了」「你解除了對 X 的拉黑（拉黑了 N 天）」，角色下次開口就知道發生過什麼。

## 二、角色拉黑用戶

- 聊天設定 Scenario 新開關「允許角色拉黑你」，預設關；開著才在穩定段教角色 `[[ACTION:BLOCK_USER|原因]]`（也認「拉黑」等別名、全形標點）。提示詞交代：只有真的被傷到、氣到不想再看到訊息時才用；不是玩笑、不是賭氣撒嬌的手段。
- 後處理（聊天頁、主動消息 1.0 背景路徑）一律剝標籤；開著才生效：這一輪的話照常落完，最後落一行系統提示「X 把你拉黑了」，發事件讓 OSContext 寫回角色。
- 被拉黑後：
  - 你照樣能打字、能送，訊息旁邊出現紅色驚嘆號＋「訊息已發出，但被對方拒收了」。
  - 不送模型、不花 API：自動回覆、延遲回覆、⚡ 都擋（⚡ 會提示「對方已把你拉黑」）。
  - 角色也不會主動找你（主動訊息 1.0、2.0 都擋，同上）。
- 解除：
  - **時間到了自己考慮**：冷靜期三檔——消氣快 3–12 小時、一般 12–48 小時（預設）、記仇 2–5 天。到點打一次 API（角色自己的模型），給它看拉黑前的對話和你拉黑期間送出的訊息，回 `{"unblock": true/false, "message": "…"}`。不解除就 24 小時後再想一次。
  - 解除時落系統提示「X 解除了對你的拉黑」，角色要是有想說的話（message）就接著落一則。
  - 第二批：臨時會話裡你說的每一句，角色回話時一起決定解不解除。
- 解除之後，角色的歷史裡那些被拒收的訊息會標上「（你拉黑對方期間收到的，當時沒看）」——它現在才看到。
- 手動救援：聊天設定頁在角色拉黑你時顯示「TA 把你拉黑了（N 天前）」，附一顆小字「強制解除」，給劇情卡住或誤觸的時候用（會落一行系統提示，角色知道是你按的）。

## 費用上限

- 用戶拉黑角色：0。
- 角色拉黑用戶：每天最多一次「要不要解除」的判斷（第一次在冷靜期結束時）。
- 第二批臨時會話：每個被拉黑的角色一天最多 3 次回覆。

## 第二批：臨時會話（待做）

- 被拉黑的一方看到「臨時會話」入口，拉黑人的一方可以在裡面回話（不算解除）。
- 雙方每天各 3 次、每次 50 字；輸入框倒數字數、顯示「今天還剩 N 次」；到角色那邊的隔天恢復（照角色時區）。
- 角色那邊也寫進提示詞：只有這幾次、每次 50 字，挑重點講。
- 你拉黑角色時，它的臨時會話訊息是你唯一看得到的東西。
- 解除後臨時會話的內容併回私聊。

## 沒做的

- 群聊不受影響：拉黑的角色在群裡照樣說話（微信也是這樣）。
- 通話：拉黑中你從通話 App 打給角色目前不擋。
